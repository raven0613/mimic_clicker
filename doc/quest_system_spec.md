# 寶箱偽裝者遊戲 — 主委託 / 次要委託系統 Spec

本文件定義委託核心規則；UI、結算整合、首輪實作範圍與驗證見[委託呈現與驗證規格](./quest_presentation_and_validation.md)。遊戲規則入口為 [spec.md](./spec.md)。

## 1. 系統目的

委託系統不是傳統 RPG 任務清單，而是用來補足本遊戲的長中短期驅動。

核心分工：

- **主要委託**：提供「我現在為什麼要繼續玩」的中長期目標，推動新寶箱怪與新內容解鎖。
- **次要委託**：提供未來數場中的短期目標，讓特定裝備暫時變成值得優先搶奪的高價值目標。
- **Jackpot**：保持獨立，負責每局最大的隨機高潮與高額收益，不作為主要內容解鎖的唯一門檻。

委託系統必須遵守：

1. 不打斷「結算後立刻再開一場」的節奏。
2. 不要求玩家在戰鬥中閱讀長文字。
3. 不要求玩家頻繁進入任務選單管理。
4. 任務目標盡量直接使用既有裝備、寶箱與 Jackpot 系統，不額外製作大量一次性內容。

## 2. 主要委託（Main Request）

### 2.1 基本規則

- 同時永遠只有 **1 個主要委託**。
- 主要委託由固定的「獵人公會窗口」發布。
- 主要委託 **自動接取**，玩家不需要按接受。
- 主要委託 **沒有期限，也沒有失敗條件**。
- 主要委託的核心目標原則上是：

> **取得指定寶箱怪所攜帶的指定裝備。**

例：

- 取得「雪鏡」。
- 取得「雪球發射器」。
- 取得「風雪之杖」。

### 2.2 一隻新寶箱對應多個主要委託

解鎖一種新寶箱怪後，不會只完成一次委託就立刻解鎖下一隻怪。

一種新寶箱怪原則上搭配 **2～3 個主要委託物品**，重要寶箱可增加到 4 個。

範例：

1. 解鎖 Frost Mimic。
2. 主要委託：取得「雪鏡」。
3. 完成後：主要委託更新為「雪球發射器」。
4. 完成後：主要委託更新為「風雪之杖」。
5. 第三個主要委託完成後，解鎖下一種寶箱怪。

目的：

- 避免玩家每打一場就完成一次主要委託並解鎖一隻新怪。
- 讓玩家有時間熟悉新寶箱怪。
- 讓「新怪剛解鎖很難打 → 逐漸能穩定打掉」形成明確成長感。
- 讓少量寶箱美術可以支撐更多 progression beats。

### 2.3 主要委託物與寶箱的關聯

每種主要委託物都屬於對應寶箱怪的特色裝備池。

例如 Frost Mimic 的裝備池可以包含：

- 雪鏡
- 冰晶戒指
- 毛皮斗篷
- 雪球發射器
- 風雪之杖

其中 2～3 件會依序成為主要委託物。

主要委託完成後，該裝備不會永久消失。之後仍可作為一般局內裝備再次出現、裝備與出售。

### 2.4 主要委託物的出現

主要委託物必須在寶箱生成時就決定是否攜帶，並且 **在戰鬥場上可見**。

不要採用：

> 寶箱死後才隨機抽是否掉出主要委託物。

玩家應在寶箱進場時就能看到：

> 「那隻身上就是我要找的東西。」

這能把該寶箱立即提升為高優先級目標。

### 2.5 主要委託物出現率

不要求每一場都必定出現，但也不允許長時間純 RNG 卡住。

建議採用「逐場提高 + 保底」，具體數值由平衡測試決定。

推薦初版概念值：

- 第 1 場：40%
- 第 2 場：65%
- 第 3 場：100%

此數值不需要展示給玩家。

### 2.6 已出現但未取得

一旦玩家曾經看到主要委託物，但該局沒有成功取得：

- 後續每場應維持高機率或直接保證再次出現。
- 不重新回到低出現率。

理由：

> 玩家已經找到攜帶者，接下來的問題應該是「能不能拿下」，而不是重新等待情報 RNG。

### 2.7 不設定「初見必敗」

新寶箱怪可以明顯比上一階段難，但不寫死玩家第一次一定無法擊破。

理想狀態：

- 一般玩家初遇時會感覺偏硬；購入對應的下一階主武器後應能穩定處理。
- 技術好、當局裝備好或運氣好的玩家，允許初見就成功。

主線節奏由「同怪多個主委託 + 任務物出現節奏」控制，而不是用 scripted loss 強迫玩家失敗。

### 2.8 主要委託物的取得方式

預設支援既有裝備震落機制。

- 主要委託物若屬於外掛裝備，可以被直接攻擊逐漸震落。
- 寶箱被擊破時，尚未震落的委託物可依既定規則取得。
- 特殊極高價值物品若需要，可單獨設定「必須擊破宿主」才可取得，但不作為所有主委託的通則。

### 2.9 主要委託完成

主要委託物在本局中仍可先作為局內裝備使用。

結算時：

1. 主要委託物不顯示一般出售價。
2. 單獨標示為 `MAIN REQUEST ITEM`。
3. 跳出主要委託完成提示。
4. 顯示固定公會窗口角色 1～2 句短對話。
5. 發放高額金錢與必要的特殊獎勵。
6. 自動更新下一個主要委託。
7. 若此物品是該寶箱怪的最後一個主要委託，則額外解鎖下一隻寶箱怪／下一段內容。

主要委託完成演出應控制在數秒內，且可快速略過或快速確認，避免阻塞下一場。

### 2.10 主要委託的獎勵

主要委託是遊戲中最高等級的固定任務獎勵之一。

可包含：

- 大額金錢。
- 特殊永久資源。
- 新寶箱怪解鎖。
- 新裝備池解鎖。
- 新牌庫／新章節進度。
- 少量永久功能解鎖。

不是每個主要委託都需要解鎖新怪。

一般情況：

- 前 1～2 個委託：主要給資源與階段進展。
- 該怪最後一個委託：提供最大的內容解鎖。

## 3. 主要委託發布方式

### 3.1 固定獵人公會窗口

為降低人物美術需求，主要委託由同一個固定公會窗口角色負責發布與回收。

不需要為每個委託製作新的 NPC 立繪。

窗口角色只需：

- 1 組主要立繪／頭像。
- 少量表情差分可選。
- 明確但簡單的固定性格。

建議說話原則：

- 平常冷靜、職業化。
- 帶少量乾式吐槽或對奇怪委託見怪不怪。
- 不進行長篇劇情。

### 3.2 對話長度

- 發布主要委託：1～2 句。
- 完成主要委託：1 句。
- 重大章節／新牌庫解鎖：最多 3～4 句。

主要委託為自動接取，對話的功能是提供世界觀與節點感，不是要求玩家閱讀才能理解機制。

## 4. 次要委託（Side Request）

### 4.1 基本定位

- 改變短期 target priority。
- 讓普通裝備偶爾變成高價值目標。
- 提供 2～5 場左右的輕度期限壓力。
- 製造「下一場我要特別注意某件東西」的再開局理由。
- 次要委託所需物品不包含新寶箱怪會掉的物品，例如現在主委託要求風雪之杖，則風雪之杖不會出現在次要委託的池中，但因為前面主委託已經解過雪鏡，則雪鏡會加入次委託池中

同時最多存在 **2 個次要委託**。

### 4.2 次要委託的取得方式

次要委託不是從主選單任務板手動挑選。

它本身是一種戰鬥場中的可見物：

> **委託單 / Request Letter**

當次要委託槽有空位時：

- 場上的隨機寶箱怪有機率攜帶一張委託單。
- 委託單在寶箱身上可見。
- 玩家可以透過震落或擊破寶箱取得。

取得委託單的當局不立刻生效。

### 4.3 結算揭示

玩家取得委託單後，在當局結算時才翻開其內容。

例：

> Raven 正在收購「紅寶石墜飾」
> 期限：3 Runs
> 一般售價：$180
> 委託收購價：$550

該次要委託從 **下一場** 起正式生效。

理由：

- 避免玩家在本局結束時才發現自己早先已經錯過目標物。
- 讓新委託自然形成「再打一場看看」的期待。

### 4.4 次要委託槽已滿

若目前已經有 2 個有效次要委託：

> **所有寶箱停止生成委託單。**

直到：

- 其中一個次要委託完成；或
- 其中一個次要委託過期。

空出委託槽後，委託單重新進入生成池。

不提供：

- 戰鬥中替換委託。
- 結算比較新舊委託。
- 額外委託背包。

目標是讓任務管理保持最小化。

### 4.5 次要委託期限

次要委託有 Run 數期限，建議約 **2～5 Runs**。

例：

> 紅寶石墜飾
> 剩餘 3 Runs

每完成一場後剩餘 Run 數 -1。

若期限歸零仍未完成：

- 委託直接過期。
- 不扣錢。
- 不扣聲望。
- 不造成永久負面效果。
- 委託槽空出。

次要委託的壓力來自「錯過高價收購機會」，而不是懲罰。

### 4.6 次要委託物的生成

有效次要委託所要求的物品，會有機會以 **可見裝備** 的形式出現在隨機寶箱怪身上。

不固定綁定某一種寶箱怪。

因此同一件委託物可能：

- 掛在脆弱普通箱上，很容易取得。
- 掛在高血量寶箱上，需要投入較多時間。
- 與主委託物或 Jackpot 同時出現，形成目標優先級選擇。

### 4.7 是否每場必定生成委託物

目前建議：**不保證每場立即出現，但期限內必須有保底。**

可採逐場提高出現率：

- 越接近期限結束，生成機率越高。
- 最後一場保證至少生成一次。

若後續實測發現隨機性造成挫折，可改為每場必定生成，但隨機掛載在不同難度寶箱上。

設計重點不是讓玩家等待純 RNG，而是：

> 委託物出現時，玩家是否願意改變目前攻擊目標去搶它。

### 4.8 次要委託物的場上提示

因為玩家已經知道自己接了該委託，當委託物出現在場上時，可以提供低干擾提示。

例如：

- 裝備旁小型委託 icon。
- 輕微框線效果。

不要使用過大的驚嘆號或全畫面提示，以免所有注意力都被次要委託綁架。

### 4.9 次要委託完成

玩家取得符合條件的裝備後，可以在本局繼續正常裝備使用。

到結算時：

- 一般裝備顯示普通售價。
- 符合次要委託的裝備旁顯示委託者頭像。
- 顯示委託收購價，高於普通出售價。
- 自動交付，不需要額外進入 NPC 畫面。

例：

> Ruby Pendant
> 普通出售：$180
> Mary 委託：$550

完成後：

- 發放委託價。
- 對應次要委託移除。
- 空出一個次要委託槽。
- 之後寶箱重新有機會攜帶新的委託單。

### 4.10 次要委託獎勵

次要委託主要提供：

- 高於普通出售價的金錢。
- 極少量特殊素材可作為稀有委託獎勵。

次要委託不應提供比主要委託更重要的永久內容解鎖。

## 5. 委託者美術策略

### 主要委託

只需要 1 位固定獵人公會窗口角色。

### 次要委託

次要委託可以只使用非常低成本的委託者表現：

- 24～48 px 小頭像。
- 徽章式頭像。
- 剪影。
- 姓名 + 小 icon。

不需要完整立繪，也不需要每個委託者都有完整對話。

同一批次要委託者可以重複出現，只是要求不同物品。

## 6. Jackpot 與委託的關係

Jackpot 不作為主要內容解鎖的唯一條件。

原因：

- Jackpot 每局都會出現。
- Jackpot 會使用各種已解鎖寶箱外皮偽裝。
- 若所有主線都要求 Jackpot，玩家沒有足夠理由去主動挑戰最新、最強寶箱怪。

因此分工如下：

### Jackpot

- 每局最大隨機事件。
- 最大即時獎勵。
- 高注意力追逐高潮。

### 主要委託

- 指向最新寶箱怪。
- 推動玩家提升永久戰力。
- 推進寶箱怪、裝備與牌庫內容解鎖。

### 次要委託

- 暫時提高某件普通裝備的價值。
- 製造接下來幾場的短期目標。

當 Jackpot、主要委託物與次要委託物同時出現時，允許玩家產生短暫 target priority 選擇。

但任何單一類型都不應永遠無條件壓過其他所有目標。

## 7. 建議的整體節奏

範例：

### 解鎖 Frost Mimic

主要委託 1：

> 取得雪鏡

玩家跑 1～2 場後取得。

主要委託 2：

> 取得雪球發射器

玩家途中買了永久傷害升級，開始能穩定處理 Frost Mimic。

主要委託 3：

> 取得風雪之杖

此物品較稀有／較難震落，是 Frost Mimic 階段的 capstone。

完成後：

> Frost Mimic 階段完成
> 解鎖下一種寶箱怪

在上述數場中，玩家同時可能：

- 遇到 Jackpot。
- 完成 1～2 個次要委託。
- 撿到新的委託單。
- 賺錢並朝下一階主武器或永久升級存錢、購買。

因此一隻新寶箱怪預期可支撐約 **4～8 場**遊戲，而不是只支撐一場。

呈現、結算整合、首輪範圍與驗證規則接續於[委託呈現與驗證規格](./quest_presentation_and_validation.md)。
