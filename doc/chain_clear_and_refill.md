# 連鎖清場與低密度續戰補場規格

本文件承接 [spec.md](./spec.md) 的普通掃場與局內成長規則，定義效果連鎖造成清場時的體驗目標、寶箱耐久分工、低密度判定、續戰補場、一次連鎖限制與驗證方式。效果的個別傷害與時序見[效果卡規格](./effect_cards.md)，生成與 runtime 邊界見[前端與遊戲執行架構](./technical_architecture.md)，完整平衡矩陣仍依[局外成長、內容與驗證規格](./progression_and_validation.md)。

## 1. 體驗目標

效果卡連鎖是局內成長的主要爆發回饋。落雷擊破帶隕石的寶箱、隕石再擊破其他效果卡攜帶者時，傷害、動畫與後續連鎖都必須完整發生，不以傷害遞減、隱藏效果抗性或降低連鎖觸發率壓制清場。

連鎖或連續點擊把場上怪物削減到少量時，玩家不應因為缺少可攻擊目標而等待上方寶箱慢慢進場。擊破使有效目標降至門檻或更少後，系統會補回可持續掃場的密度；真正清場仍是強力配置或深度連鎖偶爾達成的高潮，只有有效目標確實為零時才顯示 `CLEAR!`。

續戰補場是戰鬥節奏下限，不是額外獎勵。它不在 Jackpot 追逐期間啟動，也不能讓同一段無手動介入的自動效果永久反覆補場。

目標循環為：

> 選擇／削弱目標 → 擊破效果載體 → 連鎖掃場 → 補刀或達成清場 → 補回戰鬥密度 → 重新介入

## 2. 寶箱耐久分工

三種初版寶箱使用既有血量、收益與生成權重 config 調整，不新增效果抗性、護盾或另一套戰鬥結算：

| 寶箱怪 | 連鎖中的職責 | 初版傷害反應目標 |
| --- | --- | --- |
| `normal` | 大量、脆弱的連鎖燃料 | 初始落雷或單顆隕石可以擊破，維持大批破碎與觸發下一張效果卡的爽感 |
| `rare1` | 需要補刀的中階殘存目標 | 最大血量高於初始單顆隕石傷害；單一落雷或隕石通常將其打成殘血，兩段效果或少量武器補刀可以擊破 |
| `rare2` | 場上的耐久錨點 | 最大血量高於一張初始隕石卡全部隕石都命中時的總傷害；淺層連鎖後通常存活，深層混合連鎖或玩家事前削血仍可將其一起清除 |

規則：

- `normal` 必須維持生成池多數，不為了禁止清場而把所有寶箱一起改成高血量。
- `rare1` 應穩定出現並提供短補刀，不能像 `normal` 一樣被單顆初始隕石直接抹除。
- `rare2` 的生成占比必須足以在已解鎖階段形成偶爾可見的耐久錨點，但不得多到讓普通掃場長期只剩高血量目標。
- 玩家可先削弱 `rare1`／`rare2`，再擊破效果載體以主動提高完整清場機會；清場不能只由不可讀的亂數決定。
- 實際最大血量、基礎收益與生成權重只保存在正式 config；當前平衡報告直接讀取並記錄正式 config，不在本文件維護第二份數字，也不保留過時報告。
- 寶箱變硬後必須同步檢查收益級距，使擊破較耐久目標仍有相稱回報。

## 3. 低密度判定

### 3.1 有效場內目標

低密度與清場判定共用同一個有效目標計數。只計算目前仍可受傷，且卡牌顯示矩形與可操作場地交集比例達到 `clearRefill.minimumVisibleRatioForTarget` 的戰鬥實體：

- 普通寶箱。
- Jackpot 偽裝外殼。
- 追逐階段且仍可受傷的 Jackpot 真身。

不計入：

- 已死亡或已從 runtime 移除的實體。
- 顯示比例尚未達門檻、仍在上方入口等待帶的寶箱。
- Jackpot 僵直或正式逃跑階段。
- 裝飾模式寶箱。
- 純視覺的破碎、金幣、裝備或效果物件。

顯示交集比例門檻必須由 config 管理，不以 runtime role 或生成來源寫死另一套位置特例。上方入口寶箱未被計入有效目標時仍保留原實體、原內容與原速度，繼續向下移動。

### 3.2 建立待補場狀態

同時符合以下條件才建立一次待補場狀態：

1. 正式單局仍在進行，尚未進入回合收尾。
2. 本次狀態變化來自一隻戰鬥實體被擊破；普通寶箱自然流出場外不得主動建立補場。
3. 擊破結算後的有效目標數量小於或等於 `clearRefill.triggerMaximumEffectiveTargetCount`，初始值為 `3`。
4. Jackpot 不在可受擊的追逐階段；追逐開始時必須取消仍在等待的補場。
5. 主倒數剩餘時間不少於 `clearRefill.minimumRemainingRoundMs`。
6. 目前沒有另一個待確認、待執行或尚未重新允許的續戰補場。

經過 `clearRefill.confirmationDelayMs` 後再次檢查；有效目標仍小於或等於門檻、Jackpot 沒有進入追逐、回合仍有效且剩餘時間足夠時，才執行補場。確認期間有效目標自然增加到門檻以上、Jackpot 開始追逐或回合開始收尾時，取消本次待補場。

確認成立時若有效目標數量為 `0`，本次同時成立為真正清場；若為 `1～3`，只成立低密度補場，不視為清場。

### 3.3 自然流出與追逐例外

- 自然流出不建立新的待補場狀態，避免玩家不攻擊也能持續刷新收益目標。
- 已由擊破建立的待補場狀態不會因確認期間又有普通寶箱自然流出而取消；確認時仍依最新有效目標數量判定。
- Jackpot 追逐期間完全停用低密度與清場補場，讓玩家專注追殺；追逐結束後不追溯期間曾發生的低密度。Jackpot 逃脫不是擊破，必須等待之後的新擊破事件；Jackpot 擊破本身完成結算後若符合一般條件，則可由該次擊破建立待補場狀態。

## 4. 續戰補場

確認成立後，沿用開場填場的普通寶箱建立流程，把有效場內目標補向 `clearRefill.targetEffectiveCount`，初始值為 `12`：

- 使用當下已解鎖的唯一普通生成池與正式生成權重。
- 使用與開場填場相同的候選位置選擇器、最大重疊比例、候選次數與場內底部不可生成區。
- 每建立一隻場內寶箱就更新有效目標數量；達到 `12`、找不到合法位置或達到全場同時存在上限時立即停止。
- `12` 是補場後的有效目標上限，不是固定生成 12 隻。原本剩餘 3 隻時最多嘗試補 9 隻；若空間或全場上限不足，合法結果可以低於 12。
- 新寶箱使用完整正式內容：血量、收益、效果卡、可見／隱藏裝備、向下速度與可注入亂數都與普通生成一致。
- 補場只建立普通生成池寶箱，不建立 Jackpot、裝飾寶箱或沒有收益的特殊補場版本。
- 上方已生成但尚未完全進場的普通寶箱與 Jackpot 偽裝都保留並繼續向下移動；它們雖可能不計入有效目標，仍參與占用矩形與全場同時存在上限。
- 不重設普通上緣生成計時、Jackpot 首次生成、Jackpot 重返、主倒數或任何既有實體的位置與內容。
- Jackpot 已到預定嘗試時間且目前不存在時，該次 Jackpot 上緣生成嘗試優先於普通續戰補場，之後才以剩餘容量補普通寶箱。

若受既有實體、場地尺寸或排列限制影響而無法建立任何補場寶箱，不放寬重疊、不搬動既有實體，也不強塞寶箱；上方既有寶箱與正常生成排程繼續運作。

## 5. 一次無介入連鎖只允許一次補場

續戰補場成立時立即關閉下一次補場許可。補場前已排入前搖、飛行、持續階段或由其後續擊破產生的效果仍完整播放、造成傷害並觸發效果卡，不取消、不遞減，也不讓新生成寶箱獲得隱藏無敵。

關閉期間即使這些效果再次把新一批寶箱削減到 3 隻或更少、或全部擊破，也不得自動建立第二批補場。符合以下任一條件後，才重新允許未來的補場：

- 玩家對補場後建立或之後正常進場的有效目標造成一次有效手動武器傷害；被武器間隔拒絕的點擊、效果卡傷害與 Ring 追加攻擊都不算玩家重新介入。
- 造成前一次補場的效果連鎖及其所有後續效果已全部結束；解除時不得為關閉期間已發生的低密度或空場追溯補場，必須等待之後新的擊破事件重新通過判定。

因此，同一段沒有新手動介入且仍持續中的自動效果連鎖最多取得一次續戰補場；玩家重新攻擊後可以建立新的戰鬥段落，而已自然結束的連鎖也不會永久鎖住後續補場。

主倒數耗盡、回合收尾或場景清理時，取消待確認補場並重置所有補場狀態，不得在結算背景補生正式戰鬥寶箱。

## 6. 獎勵與回饋

- 初版不發放獨立清場或低密度補場獎勵金。補場寶箱帶來的正常擊殺收益、裝備、效果卡與後續捕獲機會就是經濟回報。
- 補場不得提高既有寶箱收益、裝備掉落率或外掛卡附著率，也不建立補場限定掉落池。
- 只有確認時有效目標為 `0` 的真正清場才顯示短促、可中斷的 `CLEAR!` 回饋；有效目標為 `1～3` 的低密度補場不顯示清場文字、音效或場地脈衝。
- 清場文字內容、顯示時間與動畫參數全部讀取清場回饋 config，不得寫死在顯示元件。回饋不得打開 Modal、暫停主倒數或要求玩家確認。
- 所有續戰補場新建立的寶箱都整批同步播放短促縮放入場：各自以原邏輯位置為中心，從零尺寸放大至略高於原始尺寸的 config 峰值，再回正至原始尺寸。不得加入逐隻延遲、入場位移或淡入；開場預填、上緣自然生成與補場前已存在的實體不套用本演出。
- 補場寶箱的戰鬥資料與完整點擊範圍在建立時立即有效；縮放只作用於內層視覺，未完成演出的寶箱仍可被手動攻擊、效果卡命中及擊破，不得形成無敵時間或延後任何結算。
- 金幣、裝備與尚未結束的效果動畫可以和新一批寶箱同時存在，但必須人工確認不會長時間遮住新的可點擊目標。

## 7. Config 權責

至少使用以下具名欄位，實際歸屬可依既有 config 職責拆分，但不得散落於傷害或 Pixi 顯示流程：

| 欄位 | 責任 |
| --- | --- |
| `clearRefill.triggerMaximumEffectiveTargetCount` | 擊破後允許建立待補場狀態的有效目標數量上限；初始為 `3` |
| `clearRefill.targetEffectiveCount` | 續戰補場嘗試達到的有效目標數量；初始為 `12`，且必須大於觸發上限 |
| `clearRefill.confirmationDelayMs` | 低密度或清場發生後再次確認的等待時間 |
| `clearRefill.minimumRemainingRoundMs` | 允許建立補場的最少主倒數剩餘時間 |
| `clearRefill.minimumVisibleRatioForTarget` | 實體被判定為有效場內目標的最小顯示交集比例 |
| `fieldFillBottomNoSpawnHeightPixels` | 開場填場與續戰補場共用的場內底部不可生成高度 |
| `clearFeedback.messageText` | 真正清場成立時顯示的文字內容 |
| 清場文字回饋欄位 | 真正清場的文字顯示時間與動畫、音效及場地脈衝參數 |
| 補場縮放入場欄位 | 補場寶箱的視覺起始倍率、放大時間、峰值倍率與回正時間 |

所有初始值只存在正式 config；本文件定義欄位語意、合法關係與行為。全場同時存在上限、候選次數、最大重疊比例、生成池權重與卡牌尺寸沿用既有正式 config，不為續戰補場複製一份。

## 8. 驗證要求

### 8.1 確定性核心測試

- 擊破後有效目標為 `0～3` 會建立待確認狀態，為 `4` 不會；自然流出、裝飾模式、回合收尾與 Jackpot 追逐都不得建立補場。
- 確認期間有效目標增加到 `4` 以上或 Jackpot 開始追逐會取消；確認期間自然流出使數量更低則仍可成立。
- 確認時為 `0` 才送出 `CLEAR!` 回饋，為 `1～3` 只補場不送出清場回饋。
- 確認等待、取消、最低剩餘時間與回合清理都使用注入的 `deltaMS`，不依賴真實時間。
- 補場沿用唯一普通生成池、位置候選與內容附著流程，固定 seed 下結果可重複；既有上方實體保留並參與重疊與容量判定。
- 補場從目前有效目標數量補向 config 目標 `12`，達標、位置不足或全場容量用完即停止，不放寬排列限制。
- 補場不建立 Jackpot，也不改動普通生成、Jackpot 首次生成或重返計時；已到期的 Jackpot 嘗試保持優先。
- 同一段沒有手動介入且仍持續中的效果連鎖最多建立一次補場；關閉期間效果仍可傷害、擊破與觸發後續效果，但不能再補場。
- 有效手動武器傷害可以重新允許後續補場；被間隔拒絕的點擊、效果傷害與 Ring 追加攻擊不得解除限制。
- 效果自然結束後可以解除限制，但不追溯關閉期間已發生的低密度或空場。
- 找不到合法補場位置時不放寬重疊、不重複發獎，回合仍能由正常排程完成。

### 8.2 批次平衡模擬

除既有必要矩陣外，模擬至少輸出：

- 每局低密度觸發、真正清場與續戰補場次數及各自分位數。
- 每次補場觸發時、補場後的有效目標數量，以及因位置或全場上限未達 12 的短缺分布。
- 每段效果連鎖的擊破數、清除場上目標比例、最大深度及是否造成完整清場。
- 清場前殘存 `rare1`／`rare2` 數量，以及玩家事前武器傷害對完整清場的貢獻。
- 最後一個有效目標被擊破至下一個有效目標出現的時間分布。
- 補場建立數、擊破數、普通收益、裝備／效果卡產出與總收益增幅。
- 補場關閉期間再次低於門檻或空場的次數，以及沒有新手動介入卻重複補場的案例數。
- 補場對 Jackpot 揭露機會、擊殺率、逃脫率及生成延後的影響；Jackpot 追逐期間補場次數必須為 `0`。

體驗目標：

- 一般操作時不應長時間只剩 1～3 個可攻擊目標；補場後應以接近 12 個有效目標為主要結果。
- 弱配置應以沒有完整清場為主要結果。
- 一般成形配置應常見大比例掃除與少量殘存目標，完整清場只偶爾成立。
- 強配置應能在一局內數次完整清場；每批都被自動效果無介入削到門檻並反覆補場視為失敗。
- 真正清場後至下一個有效目標出現的時間分位必須低於平衡模擬 config 的具名上限。
- 沒有新手動介入且同一效果連鎖仍持續時，不得發生重複續戰補場。

上述弱／一般／強配置、清除比例、清場次數、補場頻率、補場後密度、空場時間與允許收益增幅都必須在平衡模擬 config 建立具名目標；若實機校準後調整，必須重跑受影響矩陣並以當前報告直接取代舊報告。

### 8.3 人工體感

- 確認 `normal` 大量破碎、效果接力與深度連鎖仍然是本段最強視覺回饋。
- 確認普通連鎖後留下的 `rare1`／`rare2` 數量足以形成短補刀與目標選擇，不會把高潮拖成逐隻磨血。
- 確認玩家能透過先削弱耐久目標再擊破效果載體，明顯提高清場機會。
- 確認低密度補場不會被誤認為清場獎勵，真正清場的 `CLEAR!` 仍有明確辨識度。
- 確認整批補場不突兀、不遮住 Jackpot，也不打斷未完成的效果動畫；Jackpot 追逐期間畫面不補入普通怪打散焦點。
- 確認強配置能數次清場並感到成長，但仍需要重新選目標與手動介入，不能只看著遊戲永久自動運轉。
