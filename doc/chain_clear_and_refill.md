# 連鎖清場與續戰補場規格

本文件承接 [spec.md](./spec.md) 的普通掃場與局內成長規則，定義效果連鎖造成清場時的體驗目標、寶箱耐久分工、清場判定、續戰補場、一次連鎖限制與驗證方式。效果的個別傷害與時序見[效果卡規格](./effect_cards.md)，生成與 runtime 邊界見[前端與遊戲執行架構](./technical_architecture.md)，完整平衡矩陣仍依[局外成長、內容與驗證規格](./progression_and_validation.md)。

## 1. 體驗目標

效果卡連鎖是局內成長的主要爆發回饋。落雷擊破帶隕石的寶箱、隕石再擊破其他效果卡攜帶者時，傷害、動畫與後續連鎖都必須完整發生，不以傷害遞減、隱藏效果抗性或降低連鎖觸發率壓制清場。

清場應是強力配置或深度連鎖偶爾達成的高潮，不是每次普通效果都必然發生，也不是必須從遊戲中消除的狀態。難度來自玩家能否找到效果卡載體、預先削弱耐久目標、在有限時間內完成連鎖並處理殘存寶箱；真正清場後則由續戰補場立即承接，不讓成功反過來造成長時間無目標可打。

目標循環為：

> 選擇／削弱目標 → 擊破效果載體 → 連鎖掃場 → 補刀或達成清場 → 立即續戰 → 重新介入

## 2. 寶箱耐久分工

三種初版寶箱使用既有血量、收益與生成權重 config 調整，不新增效果抗性、護盾或另一套戰鬥結算：

| 寶箱怪 | 連鎖中的職責 | 初版傷害反應目標 |
| --- | --- | --- |
| `normal` | 大量、脆弱的連鎖燃料 | 初始落雷或單顆隕石可以擊破，維持大批破碎與觸發下一張效果卡的爽感 |
| `rare1` | 需要補刀的中階殘存目標 | 最大血量高於初始單顆隕石傷害；單一落雷或隕石通常將其打成殘血，兩段效果或少量武器補刀可以擊破 |
| `rare2` | 場上的耐久錨點 | 最大血量高於一張初始隕石卡全部隕石都命中時的總傷害；淺層連鎖後通常存活，深層混合連鎖或玩家事前削血仍可將其一起清除 |

規則：

- `normal` 必須維持生成池多數，不為了禁止清場而把所有寶箱一起改成高血量。
- `rare1` 應穩定出現並提供短補刀，不能像 `normal` 一樣被單顆初始隕石直接抹除。
- `rare2` 的生成占比必須足以在已解鎖階段形成偶爾可見的耐久錨點，但不得多到讓普通掃場長期只剩高血量目標。
- 玩家可先削弱 `rare1`／`rare2`，再擊破效果載體以主動提高完整清場機會；清場不能只由不可讀的亂數決定。
- 實際最大血量、基礎收益與生成權重只保存在正式 config；當前平衡報告直接讀取並記錄正式 config，不在本文件維護第二份數字，也不保留過時報告。
- 寶箱變硬後必須同步檢查收益級距，使擊破較耐久目標仍有相稱回報。

## 3. 清場判定

### 3.1 有效場內目標

清場判定只計算目前仍可受傷，且卡牌顯示矩形與可操作場地交集比例達到 `clearRefill.minimumVisibleRatioForTarget` 的戰鬥實體：

- 普通寶箱。
- Jackpot 偽裝外殼。
- 追逐階段且仍可受傷的 Jackpot 真身。

不計入：

- 已死亡或已從 runtime 移除的實體。
- 顯示比例尚未達門檻、仍在上方入口等待帶的寶箱。
- Jackpot 僵直或正式逃跑階段。
- 裝飾模式寶箱。
- 純視覺的破碎、金幣、裝備或效果物件。

顯示交集比例門檻必須由 config 管理，不以 runtime role 或生成來源寫死另一套位置特例。上方入口寶箱未被計入清場判定時仍保留原實體、原內容與原速度，繼續向下移動。

### 3.2 成立條件

同時符合以下條件才建立一次待補場清場：

1. 正式單局仍在進行，尚未進入回合收尾。
2. 本次狀態變化來自一隻戰鬥實體被擊破；普通寶箱自然流出場外不得觸發清場。
3. 擊破結算後已沒有有效場內目標。
4. 經過 `clearRefill.confirmationDelayMs` 後再次檢查仍為空場。
5. 主倒數剩餘時間不少於 `clearRefill.minimumRemainingRoundMs`。
6. 目前沒有另一個待確認、待執行或尚未重新允許的續戰補場。

確認期間新目標自然進入有效顯示範圍、Jackpot 變成可追擊狀態或回合開始收尾時，取消本次待補場；不得因曾短暫為零就事後補生一批。

## 4. 續戰補場

清場確認成立後，沿用開場填場的普通寶箱建立流程，在場內可生成矩形補足目前可用位置：

- 使用當下已解鎖的唯一普通生成池與正式生成權重。
- 使用與開場填場相同的候選位置選擇器、最大重疊比例、候選次數與場內底部不可生成區。
- 反覆建立普通寶箱，直到找不到合法位置或達到全場同時存在上限，不另設固定補場數量，也不為了填滿而放寬重疊限制。
- 新寶箱使用完整正式內容：血量、收益、效果卡、可見／隱藏裝備、向下速度與可注入亂數都與普通生成一致。
- 補場只建立普通生成池寶箱，不建立 Jackpot、裝飾寶箱或沒有收益的特殊補場版本。
- 上方已生成但尚未完全進場的普通寶箱與 Jackpot 偽裝都保留並繼續向下移動；它們同樣參與占用矩形與全場同時存在上限。
- 不重設普通上緣生成計時、Jackpot 首次生成、Jackpot 重返、主倒數或任何既有實體的位置與內容。
- Jackpot 已到預定嘗試時間且目前不存在時，該次 Jackpot 上緣生成嘗試優先於普通續戰補場，避免補場改變既定捕獲機會。

若受既有實體、場地尺寸或排列限制影響而無法建立任何補場寶箱，合法結果是本次不強塞實體；上方既有寶箱與正常生成排程繼續運作。

## 5. 一次無介入連鎖只允許一次補場

續戰補場成立時立即關閉下一次補場許可。補場前已排入前搖、飛行、持續階段或由其後續擊破產生的效果仍完整播放、造成傷害並觸發效果卡，不取消、不遞減，也不讓新生成寶箱獲得隱藏無敵。

關閉期間即使這些效果再次把新一批寶箱全部擊破，也不得自動建立第二批補場。符合以下任一條件後，才重新允許未來的清場補場：

- 玩家對補場後建立或之後正常進場的有效目標造成一次有效手動武器傷害；被武器間隔拒絕的點擊、效果卡傷害與 Ring 追加攻擊都不算玩家重新介入。
- 造成前一次清場的效果連鎖及其所有後續效果已全部結束；解除時不得為關閉期間已發生的空場追溯補場，必須等待之後新的擊破事件重新通過清場判定。

因此，同一段沒有新手動介入且仍持續中的自動效果連鎖最多取得一次續戰補場；玩家重新攻擊後可以建立新的戰鬥段落，而已自然結束的連鎖也不會永久鎖住後續清場。

主倒數耗盡、回合收尾或場景清理時，取消待確認補場並重置所有清場狀態，不得在結算背景補生正式戰鬥寶箱。

## 6. 獎勵與回饋

- 初版不發放獨立清場獎勵金。補場寶箱帶來的正常擊殺收益、裝備、效果卡與後續捕獲機會就是清場的經濟回報。
- 清場不得提高既有寶箱收益、裝備掉落率或外掛卡附著率，也不建立清場限定掉落池。
- 確認成立時畫面必須顯示短促、可中斷的清場文字；文字內容、顯示時間與動畫參數全部讀取清場回饋 config，不得寫死在規格或顯示元件。可同時播放 config 控制的音效與場地脈衝，但不得打開 Modal、暫停主倒數或要求玩家確認。
- 補場寶箱可使用 config 控制的短促入場位移、縮放或淡入，但戰鬥資料在建立時立即有效；純視覺入場不得形成未寫入核心規則的無敵時間。
- 金幣、裝備與尚未結束的效果動畫可以和新一批寶箱同時存在，但必須人工確認不會長時間遮住新的可點擊目標。

## 7. Config 權責

至少使用以下具名欄位，實際歸屬可依既有 config 職責拆分，但不得散落於傷害或 Pixi 顯示流程：

| 欄位 | 責任 |
| --- | --- |
| `clearRefill.confirmationDelayMs` | 最後目標被擊破後再次確認空場的等待時間 |
| `clearRefill.minimumRemainingRoundMs` | 允許建立補場的最少主倒數剩餘時間 |
| `clearRefill.minimumVisibleRatioForTarget` | 實體被清場判定視為有效場內目標的最小顯示交集比例 |
| `fieldFillBottomNoSpawnHeightPixels` | 開場填場與續戰補場共用的場內底部不可生成高度 |
| `clearFeedback.messageText` | 清場成立時畫面顯示的文字內容 |
| 清場回饋欄位 | 文字顯示時間與動畫、音效、場地脈衝及短促入場演出的純視覺時間與幅度 |

所有初始值只存在正式 config；本文件只定義欄位語意、合法關係與行為。全場同時存在上限、候選次數、最大重疊比例、生成池權重與卡牌尺寸沿用既有正式 config，不為續戰補場複製一份。

## 8. 驗證要求

### 8.1 確定性核心測試

- 只有擊破造成的空場可以觸發確認；自然流出、裝飾模式與回合收尾都不得觸發。
- 上方入口寶箱低於顯示比例門檻時不阻止清場，達到門檻後會取消仍在等待的確認。
- 清場確認等待、取消、最低剩餘時間與回合清理都使用注入的 `deltaMS`，不依賴真實時間。
- 補場沿用唯一普通生成池、位置候選與內容附著流程，固定 seed 下結果可重複；既有上方實體保留並參與重疊與容量判定。
- 補場不建立 Jackpot，也不改動普通生成、Jackpot 首次生成或重返計時；已到期的 Jackpot 嘗試保持優先。
- 同一段沒有手動介入且仍持續中的效果連鎖最多建立一次補場；關閉期間效果仍可傷害、擊破與觸發後續效果，但不能再補場。
- 有效手動武器傷害可以重新允許後續清場；被間隔拒絕的點擊、效果傷害與 Ring 追加攻擊不得解除限制。
- 效果自然結束後可以解除限制，但不追溯關閉期間已發生的空場。
- 找不到合法補場位置時不放寬重疊、不重複發獎，回合仍能由正常排程完成。

### 8.2 批次平衡模擬

除既有必要矩陣外，模擬至少新增：

- 每局完整清場次數、續戰補場次數與各自分位數。
- 每段效果連鎖的擊破數、清除場上目標比例、最大深度及是否造成完整清場。
- 清場前殘存 `rare1`／`rare2` 數量，以及玩家事前武器傷害對完整清場的貢獻。
- 最後一個有效目標被擊破至下一個有效目標出現的時間分布。
- 補場建立數、擊破數、普通收益、裝備／效果卡產出與總收益增幅。
- 補場關閉期間再次空場的次數，以及沒有新手動介入卻重複補場的案例數。
- 清場與補場對 Jackpot 揭露機會、擊殺率、逃脫率及生成延後的影響。

體驗目標：

- 弱配置應以沒有完整清場為主要結果。
- 一般成形配置應常見大比例掃除與少量殘存目標，完整清場只偶爾成立。
- 強配置應能在一局內數次完整清場；每批都被自動效果無介入清空並補場視為失敗。
- 一般效果連鎖應清除大部分有效場內目標，特別深的混合連鎖仍可達成完整清場。
- 真正清場後至下一個有效目標出現的時間分位必須低於平衡模擬 config 的具名上限。
- 沒有新手動介入且同一效果連鎖仍持續時，不得發生重複續戰補場。

上述弱／一般／強配置、清除比例、清場次數、空場時間與允許收益增幅都必須在平衡模擬 config 建立具名目標；若實機校準後調整，必須重跑受影響矩陣並以當前報告直接取代舊報告。

### 8.3 人工體感

- 確認 `normal` 大量破碎、效果接力與深度連鎖仍然是本段最強視覺回饋。
- 確認普通連鎖後留下的 `rare1`／`rare2` 數量足以形成短補刀與目標選擇，不會把高潮拖成逐隻磨血。
- 確認玩家能透過先削弱耐久目標再擊破效果載體，明顯提高清場機會。
- 確認清場回饋短促可讀，新一批寶箱不突兀、不遮住 Jackpot，也不打斷未完成的效果動畫。
- 確認強配置能數次清場並感到成長，但仍需要重新選目標與手動介入，不能只看著遊戲永久自動運轉。
