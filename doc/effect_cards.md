# 效果卡規格

本文件承接 [spec.md](./spec.md) 的效果卡規則，定義效果卡附著、顯示、觸發，以及落雷、隕石與龍捲風效果。連鎖造成清場後的耐久目標、判定與續戰補場見[連鎖清場與續戰補場規格](./chain_clear_and_refill.md)，裝備掉落與能力見[裝備卡與局內裝備系統規格](./equipment_system.md)，前端與 runtime 的責任邊界見[前端與遊戲執行架構](./technical_architecture.md)。

## 1. 系統定位與初版範圍

- 效果卡是附著在寶箱怪外部、可在擊破前辨識的局內目標。
- 擊破攜帶效果卡的普通寶箱、打破攜帶效果卡的 Jackpot 偽裝外殼，或擊破攜帶效果卡的 Jackpot 真身時，觸發該卡效果。
- 初版效果卡包含落雷、隕石與龍捲風；炸彈、冰凍與時鐘保留為後續效果卡。
- 寶箱的外掛卡資料與顯示結構必須容納效果卡與裝備卡，兩類內容共用候選容量與同一套扇形排列；效果結算與裝備掉落仍各自依所屬系統處理。
- 同一寶箱不得附帶重複的效果卡；落雷、隕石與龍捲風各自最多一張，不以重複卡填滿多卡容量。
- 落雷卡為 `N` 稀有度、龍捲風卡為 `SR` 稀有度、隕石卡為 `SSR` 稀有度。外掛卡正式稀有度統一為 `N`、`R`、`SR`、`SSR`、`UR`；三者目前都使用 `normal` 卡框素材，但光暈只依正式稀有度決定，不以 effect id、equipment id 或素材名稱判斷。
- 裝飾模式不附帶效果卡，也不執行效果卡攻擊。

## 2. 附著與抽選

- 普通寶箱與 Jackpot 偽裝外殼依目前外皮使用相同的效果卡附著規則與卡片容量，玩家不能藉由插卡數量或種類直接排除 Jackpot。
- 每次建立普通可戰鬥寶箱或 Jackpot 偽裝外殼時，每種已解鎖效果卡各自依 `effectCardDefinitions` 對應的 `chance` 進行一次候選抽選；裝備也依自己的 config 建立候選，兩類候選合併後才套用共用容量。
- 若候選卡數量超過該寶箱容量，使用同一個可注入亂數來源公平隨機保留至容量上限；不得用固定處理順序讓某個卡種或卡片類別永遠優先。
- 因共用容量裁切，單一卡種的最終實際附著率可能低於 config 候選抽選率；容量足夠時效果卡可以與其他效果卡或裝備卡共存。
- Jackpot 偽裝未揭露就離場並換皮重返時，依新一輪生成重新執行完整外掛卡抽選。
- 打破 Jackpot 偽裝外殼時，外殼上的效果卡正常觸發；可見裝備依裝備 config 各自判定掉落。打破外殼可以維持不產生金錢，但不得略過插卡結算。
- 偽裝外殼的外掛卡在破殼時完成結算，不轉移到 Jackpot 真身；揭露後的真身依自己的 config 與內容池重新建立獨立外掛卡集合。
- Jackpot 真身不套用普通寶箱的單卡候選機率，而是從當下已解鎖且可用的外掛卡內容池保證選取。目標張數先依 `attachedCardConfig.capacity.jackpot.minimum`、`maximum` 與 `countSelectionChances` 決定，再以公平無重複抽選取得卡片。
- 若可用唯一卡片少於抽出的目標張數，真身必須取得全部可用卡片，不得用重複卡補滿。真身內容池包含當下可用的效果卡與裝備卡，因此不保證取得特定效果卡組合。
- 附著抽選使用可注入的亂數來源，固定 seed 必須產生可重複結果。
- 附著機率、可用效果卡集合與箱種卡片容量由 config 管理，不寫死在生成事件中。

初始外掛卡容量：

| 實體／外皮 | 容量規則 |
| --- | --- |
| `normal` | 最多 1 張 |
| `rare1` | 最多 1 張 |
| `rare2` | 最多 2 張 |
| Jackpot 偽裝外殼 | 沿用目前偽裝外皮 |
| Jackpot 真身 | 保證選取；目標張數與機率依 Jackpot config，可用唯一卡不足時全部插上 |

## 3. 效果卡外觀

### 3.1 素材組裝

- 初版卡框使用 `effects/card_frame/normal.png`。
- 落雷 icon 使用 `effects/card_icon/thunder.png`。
- 隕石 icon 使用 `effects/card_icon/meteorite.png`。
- 龍捲風 icon 使用 `effects/card_icon/tornado.png`。
- 卡框與 icon 皆為 `264 × 328`，使用相同中心點與顯示尺寸直接疊合，不做非等比拉伸。
- 初始顯示尺寸為 `33 × 41`，即原始素材寬高各縮放為 `1/8`；相較前一版 `66 × 82`，寬高各縮半、顯示面積為四分之一。
- 卡框在下、icon 在上，兩者放在同一張卡的 Container 內共同定位、縮放、旋轉與退場。
- 卡片資料分別保存卡框素材 id 與正式稀有度。初版 `N`、`SR` 與 `SSR` 都明確指定目前的 `normal` 卡框；未來 `R`、`UR` 或其他內容有新卡框素材時再調整對應資料，不使用隱含 fallback。`normal` 只代表目前素材 id，不再同時代表卡片稀有度。

### 3.2 插卡位置與點擊

- 效果卡與裝備卡共用同一個右上角外掛卡扇形容器並壓在怪卡上，允許一部分超出寶箱輪廓，不建立兩套互相重疊的排列系統。
- 單張卡使用固定位置與固定角度，每隻寶箱一致，不再於生成時抽選隨機旋轉。
- 多張卡依「卡片總數＋排列索引」使用確定性的扇形位置與角度；卡組整體只做微幅順時針旋轉，卡片間可以重疊，但每張卡的 icon 必須保留足夠可見面積。
- 後方卡先繪製、前方卡後繪製；相同輸入必須得到相同順序、座標與角度，避免重新渲染或重掛層後改變牌面順序。
- 卡片顯示尺寸、卡組相對寶箱的 X／Y 偏移、整體旋轉、各張展開角度與中心間距由 config 管理。
- 寶箱原本的點擊範圍不擴成過大的外接矩形；只有寶箱本體與每張外掛卡各自的旋轉顯示矩形可以觸發同一個寶箱攻擊，重疊區域不得重複送出攻擊。
- 效果卡跟隨寶箱的流動、受擊抖動與 Jackpot 偽裝動勢，但不參與裂紋顯示。

### 3.3 像素清晰度與光芒

- 卡框與 icon 使用適合像素素材的 nearest-neighbor 取樣，並盡量以整數座標及可維持清楚像素邊緣的等比例尺寸顯示。
- 卡片的固定扇形旋轉允許產生硬邊鋸齒，但不得使用會讓整張卡模糊的縮放取樣或濾鏡。
- `N` 卡不建立光暈顯示物件；落雷與 Sword 都屬於 `N`，不得因內容種類另加光暈。
- `R`、`SR`、`SSR`、`UR` 全部使用同一套卡框形光暈：清晰描邊與模糊光層共用一條精確貼齊卡框邊界的圓角矩形路徑，不預先放大或 offset 幾何；描邊寬度與 Blur 自然向卡框外形成柔光。光暈只由正式稀有度選取，效果卡與裝備卡不得分流。
- 初始單色配色為 `R` 藍色（描邊 `#C9E9FF`、外光 `#6FB7FF`）、`SR` 紫色（描邊 `#E1C9FF`、外光 `#A66BFF`）、`SSR` 橘金色（描邊 `#FFE268`、外光 `#FFAA2D`）。Ring 與龍捲風同為 `SR`，必須使用同一份紫色稀有度光暈；隕石依 `SSR` 使用橘金色光暈。
- `UR` 使用由左上往右下的固定線性漸層，清晰描邊與模糊外光共用依序為 `#AAFF01`、`#FF8F01`、`#FF00AA`、`#AA00FF`、`#00AAFF` 的五個色碼；預設節點為 `0`、`0.25`、`0.5`、`0.75`、`1`。漸層不流動、不旋轉，只有整體透明度參與微弱呼吸。
- 光暈只比卡片外緣多出少量範圍，不向上飄移、不位移追趕、不縮放，僅做微弱透明度呼吸並與該張卡保持完全相同的 transform。
- 卡組先繪製所有光暈，再繪製所有卡框與 icon；任何前方卡的光暈都不得蓋在其他卡片 icon 上。
- 每個會發光的稀有度各自建立並共享一份穩定的清晰描邊 `GraphicsContext`、模糊層 `GraphicsContext` 與 `BlurFilter`；同稀有度的效果卡與裝備卡必須重用，不得每張卡建立濾鏡、每幀 `clear()` 重畫，或保留依卡名建立的平行光暈資源。
- `R`、`SR`、`SSR` 的描邊／外光色碼，以及 `UR` 的五個漸層節點與色碼，都由稀有度 config 管理。圓角、線寬、模糊強度／品質／padding、基礎透明度、呼吸幅度與週期也只依稀有度讀取；顏色一律使用 CSS `#RRGGBB` 字串。

## 4. 擊破觸發流程

攜帶效果卡的普通寶箱／Jackpot 真身被擊破，或 Jackpot 偽裝外殼被打破時，流程固定為：

1. 立即完成原本攻擊所造成的傷害、死亡或 Jackpot 揭露判定。
2. 取得寶箱上尚未結算的所有外掛卡；每張效果卡保留自己的排列座標與角度，從寶箱 Container 轉移到世界特效層。
3. 所有效果卡在同一個擊破事件中一起往外短促噴出，各自伴隨小幅旋轉與淡出；裝備卡同時依裝備規則進入掉落與收集流程。
4. 每張效果卡各自完成 `160 ms` 前搖後移除卡片顯示物件，並依內容 id 明確分派至落雷、隕石或龍捲風效果流程。
5. 落雷在動畫開始時立即結算一次傷害；隕石先飛行，抵達落點時結算一次傷害並切換成爆炸動畫；龍捲風依序進入開始、持續與結束階段，只有持續階段能造成接觸傷害。

規則：

- 效果卡前搖期間不先造成任何效果卡傷害。
- 同一寶箱上的多張不同效果卡一起開始前搖並各自觸發，不因排列順序延後成串行；單張效果的內部時序仍依該效果規格執行。
- 效果卡與裝備卡共存時，效果觸發與裝備／金錢噴散可以並行。Jackpot 偽裝外殼被打破時可不噴金錢，但效果卡與裝備卡結算不得省略。
- 主倒數若在 `160 ms` 前搖完成前耗盡，取消尚未發動的效果並清除噴出中的卡片。
- 已開始的落雷不因動畫速度重複造成傷害；傷害只在每道落雷開始時結算一次。
- 隕石尚未發射或仍在飛行時若主倒數耗盡，立即取消尚未落地的隕石，不播放會誤導玩家的落地爆炸，也不造成倒數後傷害。
- 主倒數耗盡時，龍捲風立即停止傷害並清除，不額外播放結束動畫。
- 任一效果卡擊破另一隻攜帶效果卡的寶箱時，允許依相同流程連鎖觸發。
- 連鎖觸發必須經過各自的 `160 ms` 前搖，不在同一個同步呼叫堆疊中無限制遞迴。
- 連鎖中的每段效果都使用原始效果傷害與觸發規則，不依連鎖深度遞減傷害，也不讓高階寶箱取得未顯示的效果抗性。
- 效果連鎖清空有效場內目標時仍完成所有已排程效果；續戰補場不取消原連鎖，但同一段沒有新手動介入且仍持續中的連鎖最多建立一次補場，完整狀態規則見[連鎖清場與續戰補場規格](./chain_clear_and_refill.md)。
- 主倒數耗盡後不得再建立新的待發動效果卡攻擊、傷害、收益或連鎖。

## 5. 落雷目標與命中

### 5.1 目標選擇

- 每道落雷發動時，從當下仍可受擊的有效怪物中隨機選擇一隻。
- 有效目標包含普通寶箱、Jackpot 偽裝外殼與追逐中的 Jackpot。
- 已死亡、已移除、裝飾模式、Jackpot 僵直或正式逃跑階段的實體不是有效目標。
- 落雷的底端命中點取目標在發動瞬間的中心座標；選定後不追蹤目標移動。
- 若發動時沒有有效目標，落雷在原攜帶者被擊破的位置播放，但不造成傷害。
- 多道落雷優先選擇不同目標；有效目標不足時才允許重複選擇。
- 目標選擇使用可注入亂數來源，固定 seed 必須可重複。

### 5.2 傷害與範圍

- 初始每張落雷卡發動 `1` 道落雷。
- 每道落雷的初始傷害為初始武器初始攻擊力的 `3` 倍。
- 初始傷害由初始武器攻擊力與落雷倍率推導，不另外保存可能互相矛盾的固定傷害數字。
- 武器後續升級不會自動放大落雷；落雷未來使用自己的效果卡強化規則。
- 被選中的目標保證受到該道落雷傷害。
- 落雷傷害集中在底端命中點附近，不是整條 `88 × 256` 雷柱都帶有傷害。
- 初始攻擊範圍是以底端命中點為中心的 `88 × 88` 正方形，向左右及上下各延伸 `44 px`；正方形邊長直接由單格 frame 寬度 `88 px` 推導，不另存一份可能互相矛盾的固定數值。
- 其他與該 `88 × 88` 正方形重疊的有效怪物也受到同一次傷害。
- 同一隻怪物每道落雷最多受傷一次，不因多幀動畫或同一範圍內重複檢查而追加傷害。
- 多道不同落雷可以各自命中同一目標；每一道都依自己的命中結果結算一次。
- 落雷傷害沿用手動攻擊的受傷、裂紋、死亡、收益與 Jackpot 揭露／擊殺流程，不建立第二套戰鬥結算；但效果卡不套用或更新每目標武器傷害間隔。

## 6. 落雷動畫

- 攻擊素材為 `effects/thunder.png`。
- 素材是 `792 × 256` 的水平精靈圖帶，由左至右排列 `9` 幀，每幀 `88 × 256`。
- AnimatedSprite 使用底部中央 anchor；底端放在命中點，雷柱由命中點向上延伸完整 `256 px`，不得再以動畫上下中心對齊目標。
- 單道落雷動畫初始總時間為 `450 ms`，九幀依總時間平均播放。
- 動畫總時間由 config 管理；調整快慢只改變視覺，不改變傷害時點、次數或數值。
- 落雷使用非循環動畫，最後一幀完成後立即從場景移除。
- 落雷必須沿用專案既有水平精靈圖帶切幀工具；同一工具也供金幣、點擊、隕石與爆炸使用，不得另寫效果專用轉動畫工具。
- 原始 texture source 與切出的 frame texture 由同類落雷共享，不為每一道落雷重複載入或切圖。

## 7. 隕石效果

### 7.1 稀有度、素材與動畫

- 隕石效果卡 id 為 `meteorite`，正式稀有度為 `SSR`，目前使用 `effects/card_frame/normal.png` 與 `effects/card_icon/meteorite.png` 疊合。
- 場上隕石素材為 `effects/meteorite.png`，是 `1410 × 500` 的水平精靈圖帶，由左至右排列 `6` 幀，每幀 `235 × 500`。
- 隕石的實際顯示尺寸為單格 `235 × 500` 的寬高各乘上正數 `meteorite.displayScale`；以底部中央作為飛行前端／落地 anchor，整體順時針旋轉 `45°`，沿右上到左下方向飛行。`displayScale` 只控制顯示與由顯示衍生的幾何，不改動素材來源或切幀尺寸。
- 隕石飛行動畫每輪時間讀取 `effectCardConfig.meteorite.animationCycleDurationMs`；循環速度與位移速度互相獨立，調整動畫快慢不得改變抵達落點的時間。
- 隕石飛行速度讀取 `effectCardConfig.meteorite.flightSpeedPixelsPerSecond`，以 `deltaMS` 更新位置並避免跨越落點。
- 爆炸素材為 `effects/explode.png`，是 `1536 × 240` 的水平精靈圖帶，由左至右排列 `6` 幀，每幀 `256 × 240`。
- 爆炸與隕石共用同一個 `meteorite.displayScale`，實際顯示尺寸為單格 `256 × 240` 的寬高各乘上該比例；仍使用底部中央 anchor，非循環動畫總時間讀取 `effectCardConfig.meteorite.explosionAnimationDurationMs`，播放完成後只清除顯示物件，不再改變戰鬥結果。
- 隕石飛行前端、爆炸底部中央與傷害區底線永遠共用同一個落點座標。調整 `displayScale` 只能改變三者由該 anchor 向外延伸的尺寸，不得額外平移任何一層。
- 隕石、爆炸、落雷、點擊特效與金幣圖帶都必須沿用專案唯一的水平精靈圖帶切幀工具，不得建立另一套轉動畫工具。

### 7.2 隨機落點與場外起點

- 每顆隕石在發射前先使用可注入亂數決定自己的落點；落點不鎖定怪物，因此可能命中多隻怪物，也可能完全沒有命中。
- 落點代表隕石飛行前端與爆炸底部中央共同對齊的座標，不使用每幀透明像素的最低點作為戰鬥座標。
- 令縮放後爆炸實際顯示寬度為 `V = 256 × meteorite.displayScale`，傷害正方形邊長為 `D = V × meteorite.damageAreaWidthMultiplier`。落點範圍必須讓完整 `D × D` 傷害正方形位於遊戲 canvas 內；水平中心與左右邊界至少相距 `D ÷ 2`，底線與畫面頂端至少相距 `D`。
- 決定落點後，沿飛行方向的反向射線推算右上方起點。起點必須使用縮放後且旋轉完成的隕石顯示範圍，確保整個 Sprite 位於畫面外再進場，不使用原始 frame 尺寸或與畫面尺寸無關的固定起點。
- 隕石選定落點後不追蹤怪物，也不因場上實體移動而改變軌跡。
- 給定相同且在新範圍內合法的落點座標，調整比例不得改變隕石、爆炸或傷害區的 anchor 座標；但合法落點區間會隨 `D` 改變，因此同一個正規化亂數在調整比例前後可以映射到不同的絕對座標。

### 7.3 顆數、錯開與傷害

- 每張隕石卡的發射顆數讀取 `effectCardConfig.meteorite.initialMeteoriteCount`，每顆獨立決定落點。
- 第一顆立即發射；後續每顆在上一顆的發射時間後，累加由 `minimumLaunchIntervalMs` 與 `maximumLaunchIntervalMs` 定義的隨機間隔。間隔使用可注入亂數，相同 seed 必須可重複。
- 每顆隕石的飛行距離可因落點不同而不同，因此實際落地時間除發射間隔外，也會自然受到飛行距離影響。
- 隕石抵達落點的同一瞬間移除飛行 Sprite、建立爆炸 Sprite，並結算一次範圍傷害。
- 每顆隕石的初始傷害為初始武器初始攻擊力的 `4` 倍，目前即 `40`；正式 config 保存傷害倍率，不另存會和初始武器攻擊力矛盾的固定傷害數字。
- 傷害範圍為 `D × D` 正方形，`D = 256 × meteorite.displayScale × meteorite.damageAreaWidthMultiplier`；與爆炸共用底部中央 anchor，左右各延伸 `D ÷ 2`，並從落點底線向上延伸 `D`。
- `meteorite.damageAreaWidthMultiplier` 預設為 `1` 且必須大於 `0`；`1` 代表傷害正方形邊長等於爆炸實際顯示寬度，`1.1` 代表邊長比實際顯示寬度增加 `10%`。倍率只從同一個底部中央 anchor 向外改變範圍，不得移動隕石或爆炸。
- 傷害範圍邊長由爆炸單格 frame 寬度、共用顯示比例與傷害範圍倍率推導，不另外維護像素常數。調整顯示比例或傷害範圍倍率都屬於戰鬥範圍變更，必須重跑受影響測試與平衡模擬。
- 每顆隕石對範圍內同一實體最多造成一次傷害；不同隕石的範圍可以重疊，同一實體可以分別受到每顆隕石一次傷害。
- 可受擊實體規則與落雷一致；傷害沿用手動攻擊的受傷、裂紋、死亡、收益、效果卡連鎖與 Jackpot 結算入口。

## 8. 龍捲風效果

### 8.1 稀有度、素材與階段

- 龍捲風效果卡 id 為 `tornado`，正式稀有度為 `SR`，目前使用 `effects/card_frame/normal.png` 與 `effects/card_icon/tornado.png` 疊合；卡片使用第 3.3 節的共用卡框形 `SR` 光暈，顏色與亮度依 config。
- 場上素材分為 `effects/tornado_start.png`、`effects/tornado_run.png` 與 `effects/tornado_end.png`。三張都是水平精靈圖帶，每幀 `120 × 265`；開始圖帶為 `600 × 265`、`5` 幀，持續圖帶為 `360 × 265`、`3` 幀，結束圖帶為 `600 × 265`、`5` 幀。
- 三張圖帶必須沿用專案唯一的水平精靈圖帶切幀工具與共享 texture 資源，不得建立龍捲風專用切幀器，也不得為每個實例重新切圖。
- 每張卡在共通前搖完成後，於被擊破攜帶者的位置依 config 建立龍捲風；若顯示範圍超出場地，只校正到最近的合法場內位置。多個龍捲風同時建立，不逐顆延後。
- 每個龍捲風以底部中央為位置 anchor，依序執行 `start → run → end`。`start` 與 `end` 各播放一次，`run` 循環播放直到持續時間耗盡；三段動畫時間與 `run` 持續時間分別讀取 config。
- `start` 與 `end` 不造成傷害，但位置仍持續往前更新，避免動畫切換時突然停住。`run` 持續時間不包含 `start` 與 `end`；跨階段時必須消耗同一次更新剩餘的 `deltaMS`，不得因掉幀延長實際存活或傷害時間。
- `end` 播放完成後移除龍捲風；若主倒數先耗盡則立即清除所有待建立與場上龍捲風，不播放 `end`，也不得再造成傷害或觸發連鎖。

### 8.2 移動與多顆方向

- 單顆龍捲風建立時使用可注入亂數決定初始方向；`start` 沿該方向直行，`run` 以 config 速度移動，並在 config 的最短／最長轉向間隔內抽選下一次轉向時間與受限轉角，形成可讀但漫無目的的遊走。
- `run` 碰到場地邊界時依碰撞邊界反射並修正回合法範圍，不能長時間離開畫面。轉向與反射只改變移動方向，不得改變動畫播放速度或傷害間隔。
- `run` 結束時保存當下方向與速度；`end` 沿該方向繼續移動且不再抽選新轉向，碰到邊界仍照常反射。
- 同一張卡建立 `N > 1` 個龍捲風時，先抽選一個全域基準角度，再以完整圓周的 `N` 等分方向分配各實例，最後分別加入 config 限制內的小幅角度擾動。不得只讓每顆獨立任意抽方向，導致多顆長時間重疊或朝向幾乎相同。
- 每個龍捲風擁有獨立的轉向排程與亂數結果；相同 seed 與相同 `deltaMS` 序列必須重現相同路徑、反射與階段切換。

### 8.3 傷害範圍與間隔

- 只有 `run` 階段可以造成傷害；進入 `run` 後第一次與有效目標重疊時立即結算，不必先等待一個傷害間隔。`start`、`end` 與主倒數結束後都不做命中判定。
- 龍捲風初始傷害由初始武器攻擊力乘上 `initialWeaponDamageMultiplier` 推導，不保存可能互相矛盾的固定傷害值；目前規劃的初始倍率與之後調整皆以 config 為準，武器後續升級不會自動放大龍捲風。
- 令顯示比例為 `S = tornado.displayScale`、傷害高度比例為 `R = tornado.damageAreaHeightRatio`，則傷害矩形寬度 `W = 120 × S`、高度 `H = 265 × S × R`。矩形以龍捲風底部中央 anchor 為底線，左右各延伸 `W ÷ 2` 並向上延伸 `H`。
- `damageAreaHeightRatio` 必須大於 `0`；調整 `displayScale` 會同步改變視覺尺寸與傷害矩形，調整高度比例只改變由同一底線向上延伸的傷害高度，兩者都不得平移位置 anchor。
- 傷害矩形與既有有效目標碰撞範圍重疊時才算命中；不得使用 Pixi `getBounds()` 或透明像素內容作為戰鬥真相，幾何計算必須放在可獨立測試的純邏輯中。
- 每個「龍捲風實例 × runtime 目標」各自保存上次傷害時間，同一組合達到 config 傷害間隔後才能再次受傷。離開後重新進入不會提早重置；不同龍捲風命中同一目標則可各自獨立造成傷害。
- Jackpot 從偽裝外殼變成真身時，該 runtime 實體對所有場上龍捲風的傷害間隔立即歸零；若仍重疊，可在下一次更新立即受傷，但同一次傷害呼叫不得同時對外殼與真身重複結算。
- 有效目標、共用受傷／死亡／收益／Jackpot 結算與連鎖入口都與落雷一致；龍捲風傷害不套用或更新武器傷害間隔。

## 10. 驗證要求

### 10.1 確定性核心測試

- 普通寶箱與 Jackpot 偽裝外殼依 config 執行的效果卡與裝備候選抽選在固定 seed 下可重複；候選超過共用容量時的保留結果公平且可重複，不依類別或卡種宣告順序固定偏向其中一張。
- Jackpot 真身不呼叫普通候選機率；目標張數依 `countSelectionChances` 可重複抽選，並從效果卡與裝備共同內容池公平、無重複選卡且不超過 config 上限。
- 外掛卡完整內容識別不重複，並受各箱種與 Jackpot 偽裝外皮容量限制；可用種類不足時不以重複內容補滿。
- 單張與多張卡的扇形位置、角度、繪製順序與旋轉矩形命中結果由卡片總數及索引確定，不依賴亂數或真實時間。
- 共用稀有度解析只依 definition 的 `N`／`R`／`SR`／`SSR`／`UR` 決定光暈設定：`N` 回傳無光暈，效果卡與裝備卡的相同稀有度回傳相同設定，且結果不因內容 id 或 `normal` 卡框素材而改變；`UR` 的固定斜向五個節點與色碼直接讀取正式 config。
- 同一寶箱的多張不同效果卡會在同一擊破事件中一起進入各自前搖；效果卡與裝備卡的結算互不漏失或重複。
- Jackpot 偽裝外殼被打破時即使不產生金錢，也會觸發效果卡並依裝備 config 完成可見與隱藏裝備結算。
- 落雷只從有效目標中選擇，且沒有目標時不產生傷害。
- 落雷動畫底端正確對齊命中點，範圍判定使用其周圍 `88 × 88` 正方形而非整條雷柱。
- 每道落雷對每隻命中怪物只造成一次傷害。
- 落雷傷害正確沿用普通死亡、收益、Jackpot 揭露及 Jackpot 擊殺流程。
- 落雷、隕石或龍捲風擊破另一張效果卡時會建立下一段前搖並連鎖觸發，不發生同步無限遞迴或重複結算。
- 連鎖清場後仍在前搖、飛行或持續階段的效果可命中續戰補場寶箱；沒有新手動介入時不得因同一持續連鎖再次補場，也不得為限制補場而取消傷害、後續效果或建立隱藏無敵。
- 主倒數在前搖期間耗盡時，所有待發動效果被取消。
- 隕石隨機落點使套用顯示比例與傷害範圍倍率後的完整 `D × D` 傷害區位於 canvas 內；測試必須驗證倍率 `1` 與 `1.1` 都依公式產生正確邊長，且不改變既定落點 anchor。場外起點只使用縮放後的旋轉 Sprite bounds，位於落點右上方且初始完全不可見。
- 隕石使用指定速度沿固定向量前進，不跨越落點；落地時只造成一次傷害，後續爆炸幀不重複傷害。
- 多顆隕石依 config 產生的發射間隔、獨立落點與各自命中結果在固定 seed 下可重複。
- 主倒數耗盡時，尚未發射與仍在飛行的隕石被取消且不造成傷害。
- 龍捲風依 `start → run → end` 正確切換，只有 `run` 造成傷害；大步 `deltaMS` 跨階段不會遺失剩餘時間、延長存活或在無傷害階段誤傷。
- 龍捲風移動、限角轉向、邊界反射與多顆等分方向在固定 seed 與固定 `deltaMS` 序列下可重複，且多顆初始方向不會退化成全部相同。
- 龍捲風傷害矩形依 `displayScale` 與 `damageAreaHeightRatio` 公式計算；第一次重疊立即命中，同一實例與目標達到 config 間隔才可再次受傷，不同龍捲風則獨立計時。
- Jackpot 由偽裝切換真身時會清除該實體的所有龍捲風傷害間隔，下一次重疊更新可立即受傷，但同一次結算不重複傷害。
- 主倒數耗盡時，待建立與所有階段的龍捲風都立即取消，不播放結束動畫、不造成傷害或建立新連鎖。
- 水平精靈圖帶工具正確產生落雷、隕石、爆炸、龍捲風三階段與點擊特效所需 frame，並拒絕尺寸不符的素材。

### 10.2 平衡與人工檢查

- 落雷、隕石與龍捲風都會改變擊殺數、收益、Jackpot 揭露與捕獲機會，必須依[局外成長、內容與驗證規格](./progression_and_validation.md)執行受影響的完整核心測試與固定 seed 平衡模擬。
- 人工確認單張 `33 × 41` 效果卡固定插在右上角，多張卡呈現整體微幅順時針的撲克扇形，不會隨生成隨機歪斜。
- 人工確認扇形重疊後每張卡的 icon 仍可辨識，突出部分的點擊範圍貼合各張卡片，不會在明顯空白處命中寶箱。
- 人工確認卡片縮放與固定扇形角度沒有模糊或持續閃爍。
- 人工確認 `N` 卡完全沒有光暈；`R` 藍色、`SR` 紫色、`SSR` 橘金色與 `UR` 固定斜向五色光暈清楚但不覆蓋鄰卡 icon，只做微弱呼吸並與卡片完全同步移動，沒有落後、追趕或位置重設。
- 人工確認落雷底端落在寶箱中心附近，視覺雷柱不再以下中心壓住寶箱。
- 人工比較落雷 `450 ms` 初始速度，必要時只調整 config 後重新確認。
- 人工確認 `R`、`SR`、`SSR` 的清晰描邊都貼齊卡框、模糊光層自然向外衰減，微弱呼吸與卡片完全同步，且三種單色容易區分。
- 人工確認縮放後的隕石順時針旋轉 `45°` 後確實從右上往左下進場，起始幀不會先閃在畫面內。
- 人工確認調整共用 `displayScale` 或 `damageAreaWidthMultiplier` 前後，隕石飛行前端、爆炸底部與傷害區底線仍落在同一位置，切換時沒有跳動；倍率為 `1` 時視覺爆炸寬度必須與實際受傷範圍一致，其他倍率則確認額外容差符合設定值且不產生難以理解的遠距命中。
- 人工確認多顆隕石錯開發射後節奏自然，不會完全同時，也不因飛行距離差異拖得過長。
- 人工確認目前 config 的飛行速度、飛行循環與爆炸速度不會長時間遮擋寶箱點擊。
- 人工確認 `UR` 的五色固定斜向漸層依指定順序同時套用於描邊與模糊外光，沒有色帶流動、每幀重建或因卡片旋轉而脫離卡框。
- 人工確認龍捲風三段動畫銜接不中斷位移，`run` 遊走與碰牆反射可讀，多顆初始方向明顯不同且不會長時間疊在一起。
- 人工以傷害範圍邊界內外的寶箱確認龍捲風只在顯示寬度與設定高度比例覆蓋處命中，單目標傷害節奏符合 config，主倒數結束後畫面與傷害都立即清除。

## 11. 後續效果卡方向

### 炸彈

- 對周圍多張寶箱造成傷害，用來加速掃場、提高單位時間擊破數並間接增加找到 Jackpot 的機會。
- 範圍傷害不改變可見裝備的掉落率，也不額外產生隱藏裝備。

### 冰凍

- 擊破攜帶冰凍卡的寶箱時，凍結附近怪物一小段時間。

### 時鐘

- 增加主倒數時間，作為純粹延長單局的資源。
- 必須設定同局加時上限，避免時鐘成為永遠的唯一最優目標。
