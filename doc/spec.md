# 寶箱偽裝者遊戲企劃書

## 1. 專案概述

> 在限時內打爆不斷流過的寶箱，找出唯一混在其中的偽裝 Jackpot；一旦揭穿，它就會活過來滿場逃跑——追上它，打爆它，拿走本局最大獎。

### 遊戲定位

一款以「持續敲擊寶箱、尋找偽裝頭獎、短局反覆成長」為核心的 Active Incremental / Clicker 遊戲。

玩家在限時內攻擊不斷由上往下緩慢流動的寶箱卡牌，盡可能打破更多寶箱、取得金錢與局內裝備，並從中找出每局唯一的「偽裝 Jackpot」。

普通寶箱即使流出場外也不會造成直接懲罰，只代表玩家錯過該目標與它可能帶來的收益。

偽裝 Jackpot 則會混入普通寶箱之中，以不同寶箱外皮偽裝。若玩家沒能在它流出場前揭穿，它會在短暫等待後換一個外皮重新混入場中，且每次重新出現的間隔逐漸增加。

當 Jackpot 的偽裝外殼被打破後，它會現出真身並開始在場地中高速移動，以可讀的直線路徑撞牆反彈，最後往下方出口逃走。玩家必須在它逃脫前追上並擊破，才能取得本局最大獎勵。

## 2. 核心體驗目標

遊戲希望提供以下節奏：

1. 平常大部分時間可以無腦、舒服地敲擊寶箱。
2. 玩家偶爾會因高價值裝備、效果卡或可疑行為而改變目標。
3. 每局都有一個明確的 Jackpot 懸念。
4. 玩家不需要仔細推理也能正常玩，但注意到偽裝者的細微破綻可以提高效率。
5. Jackpot 現形後，操作強度突然提升，形成短時間追逐高潮。
6. 一局結束後快速結算、購買永久升級並立即再開一局。
7. 長期形成「再打一場就能再升一級／再抓一次 Jackpot」的循環。

核心節奏可概括為：

> 掃箱 → 找可疑目標 → 揭穿偽裝 → 追殺 Jackpot → 大量噴獎 → 結算升級 → 再來一局

## 3. 單局流程

### 3.1 開局

- 玩家帶著永久主武器進場。
- 開始固定時間倒數。
- 初版只有一個關卡，場地依各寶箱怪的生成權重，持續生成所有已解鎖種類。
- 寶箱會從上方向下緩慢移動。
- 普通寶箱移出場外沒有直接懲罰。

### 3.2 普通掃場階段

玩家在場中自由挑選寶箱攻擊。

主要目標包含：

- 普通寶箱：提供基本金錢與隨機掉落。
- 高級寶箱：較硬，但內部收益更高。
- 身上插有高稀有裝備卡的寶箱：明確的高價值目標。
- 帶效果卡的寶箱：擊破後觸發炸彈、冰凍、時鐘等效果。
- 偽裝 Jackpot：外觀看似普通寶箱，但會有極輕微的行為破綻。

玩家的普通決策應維持非常簡單：

> 打脆箱找 Jackpot、打肥箱拿好東西、打效果箱延長或加速本局。

### 3.3 Jackpot 揭露

當玩家打破偽裝 Jackpot 的外殼後：

- Jackpot 顯示真身。
- 取得獨立的 Jackpot 血量。
- 進入高速追逐狀態，此時才顯示並啟動 Jackpot 倒數條。
- 以帶有規律的直線路徑移動，撞牆時依合理角度反彈。
- 只使用微幅旋轉來表現動勢，不做持續翻滾。
- Jackpot 倒數耗盡時，先在原地短促抖動僵直，再由當下位置垂直向下逃走。

Jackpot 現形時可搭配：

- 短暫畫面定格。
- 特殊音效。
- 卡框或背景視覺變化。
- 向上或側邊彈開一段距離。
- 0.5～1 秒短暫控制效果，讓玩家有反應時間。

### 3.4 Jackpot 結果

#### 擊破成功

- Jackpot 大量噴出金錢。
- 高機率或保證掉落高稀有裝備。
- 可額外掉落特殊局外素材。
- 本局 Jackpot 不再生成。

#### 逃脫

- Jackpot 從下方離場。
- 不額外扣除主倒數時間。
- 玩家只是失去本局最大獎。
- 若 Jackpot 倒數先耗盡，普通遊戲可以持續至主倒數結束。
- 若主倒數在追逐中先耗盡，Jackpot 仍須完成「原地抖動僵直 → 垂直向下逃走」，之後才進入結算。

## 4. 偽裝 Jackpot 系統

### 4.1 基本規則

- 每局只有一個 Jackpot 實體。
- Jackpot 的偽裝池必須與目前關卡實際可能生成的寶箱怪種類一致。
- 它以普通寶箱的形式混入正常寶箱流。
- 玩家若沒有在它離場前揭穿，它會暫時離場。
- 經過一段等待時間後，Jackpot 會換一個隨機外皮再次混入場中。
- 每次未揭露就流走後，重返間隔逐漸增加，越晚抓到，本局剩餘捕捉機會越少。
- Jackpot 真正被擊殺後，本局不再重新生成。
- Jackpot 偽裝進場時不顯示額外時間條；只有外殼被打破、開始追逐後，才顯示與主倒數有明顯區別的 Jackpot 倒數條。
- 主倒數或 Jackpot 倒數任一條先耗盡，都會終止本次捕獲機會。
- Jackpot 獎勵以目前關卡可生成寶箱怪的最高收益為基準，再依 Jackpot config 放大，不使用完全固定的跨進度獎勵。

### 4.2 換皮的目的

換皮的主要目的：

- 避免玩家第一次辨認後，之後只需固定追同一張卡。
- 保留每一輪重新辨認的懸念。
- 讓新解鎖寶箱外皮同時增加偽裝池內容。
- 強化「同一隻生物會換殼混回來」的角色感。

### 4.3 身份連續性

即使外皮改變，Jackpot 應保留少量固定性格／破綻，讓玩家感覺它仍然是同一隻生物。

例如：

- 特定節奏的輕微抖動。
- 鄰近寶箱被攻擊時稍微縮一下。
- 游標靠近時偶爾停頓。
- 偶爾閃過特殊色像素。
- 接近離場時出現短促異常動作。
- 固定的小音效或影子特徵。

### 4.4 破綻原則

破綻不能變成必須掌握的推理規則。

目標是：

- 新手：無腦大量打箱，也有機會自然找到 Jackpot。
- 熟練玩家：注意細節後能提高找到 Jackpot 的效率。

不要讓每輪固定使用完全相同動畫，以免變成單純 UI 標記。

可使用「固定性格 + 隨機破綻」：

- 固定性格：每次都有一個小反應。
- 隨機破綻：每輪再抽 1～2 個額外行為。

### 4.5 真身追逐與退場

- Jackpot 在兩次碰牆之間維持可讀的直線移動，不無理由頻繁隨機轉向。
- 撞牆時依牆面法線反射速度方向；只允許極小且有上限的角度修正，避免完全水平、垂直或無限重複路徑。
- 追逐旋轉僅為微幅傾斜，最大角度、回正速度與碰撞偏移皆由 config 管理。
- 進入倒數耗盡退場後，Jackpot 立即停止受擊，在原地做短促抖動僵直。
- 僵直完成後鎖定當下水平位置、忽略側牆碰撞，直線向畫面下方離場。
- Jackpot 倒數先耗盡時，只結束 Jackpot 捕獲，主倒數與普通掃場繼續。
- 主倒數先耗盡時，立即禁止全部戰鬥操作，待 Jackpot 完成相同退場後進入結算。

## 5. 寶箱流動

### 5.1 普通寶箱

- 從場地上方向下緩慢流動（上到下20秒）。
- 離場不扣血、不扣時間。
- 離場只代表玩家錯過該寶箱及其收益。
- 普通寶箱移動速度應足夠慢，避免變成純反應型遊戲。

### 5.2 受擊反應

寶箱被攻擊時，應有明確但低成本的卡牌動態：

- 輕微抖動。
- 卡片後仰。
- 橫向偏移。
- 短暫停止下滑。
- 裂紋逐步增加。
- 重擊時可往上彈一小段。

受擊反應的目的：

- 提供打擊感。
- 避免靜態卡牌像純 UI。
- 讓玩家在連續攻擊同一目標時有「黏著」感。

寶箱受擊時低機率觸發向上逃跑：

- 只剩 15% HP 時低機率觸發
- 一開始先有 0.2～0.4 秒「嚇到」的預備動作，再開始往上跑。
- Z 軸拉到最前
- 路線基本是直線
- 1～3 下通常能補死
- 沒有第二時間條
- 往上消失後就是真的沒了

#### 和 Jackpot 受擊反應差異

普通箱：
↓ 緩慢流動
瀕死偶爾 → ↑ 慢速逃跑

偽裝 Jackpot：
↓ 假裝普通
被揭露 → ↔↗↘ 高速直線反彈
Escape Bar 結束 → ↓↓↓ 正式逃離

限制：

- 同時最多 1～2 隻普通逃跑箱
- 觸發率低
- 不左右蛇行，頂多卡片本身抖動
- 不做大量粒子
- 不給巨大 UI

### 5.3 場地排列

採用無固定軌道的受限隨機排列：

- 水平位置在場地安全範圍內連續分布，不切成可辨認的垂直路線。
- 卡牌應呈現自然散落感，允許少量重疊，但不得遮住過多可點擊區域。
- 生成時從多個候選位置選擇與現有卡牌重疊最少者。
- 若暫時沒有位置符合最大重疊限制，短暫延後生成，不強制塞入嚴重重疊的位置。
- 場地安全邊距、最大重疊比例、候選次數與重試間隔都由 config 管理。
- Jackpot 真身可脫離普通流動規則滿場移動，並固定顯示在所有普通寶箱之上。

## 6. 寶箱種類

### 普通寶箱

- 基礎血量。
- 基礎金錢與掉落。

### 高級寶箱

- 血量較高。
- 內部收益與稀有度較高。
- 更可能帶高稀有裝備。

初版以 `normal`、`rare1`、`rare2` 三種寶箱怪建立這個強度階梯；詳細解鎖與生成規則見[初版單關卡與前三局解鎖規格](./initial_release.md)。

### 帶裝備卡&效果卡寶箱

- 外部可見一張或多張裝備卡插在寶箱卡旁邊。
- 玩家一眼即可判斷其價值。
- 裝備可以在寶箱死亡前被攻擊「震落」。

若有效果卡擊破時觸發特殊效果，例如：

- 炸彈。
- 冰凍。
- 時鐘。
- 其他未來特殊效果。

## 7. 裝備卡系統

### 7.1 裝備定位

裝備是局內即時強化。

特性：

- 寶箱身上可見裝備卡。
- 玩家可優先追擊高稀有裝備。
- 裝備取得後立即進入空裝備槽並生效。
- 一局結束後，所有局內裝備強制轉換成局外資源，不永久保留完整裝備。

### 7.2 裝備槽

建議：

- 初始 2～3 格。
- 局外永久升級可擴充。
- 最終上限約 5 格。

若裝備槽已滿：

- 新裝備進入背包。
- 玩家可主動暫停整理。
- 不強制中斷戰鬥。

### 7.3 裝備震落

身上插有裝備卡的寶箱，在受到直接攻擊時，裝備會逐漸鬆動。

不每一下都用固定低機率獨立抽是否掉落，原因：

- 會鼓勵玩家對每隻箱子都先摸幾下。
- 血量越高反而可能因承受更多攻擊而更容易掉裝。
- 玩家永久傷害提高後，反而會減少攻擊次數，造成掉落率變低的矛盾。

應使用「鬆動值」：

- 每次直接命中增加裝備鬆動進度。
- 裝備卡視覺逐漸歪斜、晃動。
- 到達帶隨機浮動的門檻後，裝備被震飛。
- 震落後立即取得並自動裝備。
- 已震落裝備不會在寶箱死亡時再次掉落。

### 7.4 寶箱死亡時的裝備

如果裝備尚未震落，而寶箱被擊破：

- 依目前鬆動程度進行最後掉落判定。
- 鬆動程度越高，掉落率越高。
- 已震落的裝備不再重複計算。

### 7.5 範圍傷害

為避免爆炸一次震落大量裝備：

- 直接攻擊累積完整鬆動值。
- 範圍與連鎖的傷害只累積少量鬆動值，或僅在擊殺時處理掉落。

### 7.6 裝備卡種類

- 一般加攻擊力的
- 帶效果的，例如冰凍之杖：jackpot 出現的時候施加霜凍，使其一出場就動作變慢持續1秒

## 8. 寶箱內部掉落

寶箱本體被擊破後，會另外計算內部掉落。

可能內容：

- 金錢。
- 裝備。
- 特殊素材。
- 效果卡。
- 其他隨機裝備卡。

重要規則：

- 已經從外部震落的裝備，不會在內部掉落再次生成。
- 外部裝備是「看得到、可以搶」的明確獎勵。
- 內部掉落則是「打破後才知道」的不確定獎勵。

## 9. 效果卡

### 炸彈

用途：

- 對周圍多張寶箱造成傷害。
- 加速掃場。
- 提高單位時間擊破數。
- 間接增加找到 Jackpot 的機會。

注意：

- 範圍傷害不應過度提高裝備震落效率。

### 冰凍

用途：

- 擊破帶著冰凍卡的寶箱的話附近的怪會凍結少許時間

### 時鐘

- 增加主倒數時間。
- 是純粹的延長單局資源。

需要限制：

- 同局加時上限。
- 避免時鐘成為永遠的唯一最優目標。

## 10. 主武器與攻擊

### 10.1 手動攻擊

- 玩家以滑鼠點擊寶箱造成傷害。
- 主要回饋來自：卡牌晃動、裂紋、打擊音效、掉錢、裝備鬆動。

### 10.2 懸停自動攻擊

局外可解鎖：

- 游標停留在寶箱上時，每隔 X 秒自動攻擊一次。
- 手動點擊仍然正常計算。
- 永久升級可以縮短自動攻擊間隔。

目的：

- 降低長時間點擊疲勞。
- 保留手動點擊的主動加速感。

自動攻擊不能強到完全取代玩家：

- 可設定頻率上限。
- 手動攻擊仍明顯提高輸出。
- 某些裝備與重擊效果只由手動攻擊觸發。

### 10.3 未來武器差異

不同武器不只提升傷害，也可帶有不同攻擊特性，例如：

- 大錘：單擊高傷。
- 雙刃：一次兩段傷害。
- 鑿子：對高防寶箱更有效。
- 震盪錘：更容易震落裝備。
- 追蹤型武器：更容易攻擊 Jackpot。

## 11. 局內成長

玩家在一局內透過：

- 撿到裝備。
- 更換／疊加裝備。
- 取得效果卡。
- 延長時間。
- 建立更高的掃場與追殺效率。

希望形成：

> 前段普通 → 中段裝備逐漸成形 → Jackpot 出現時火力爆發 → 擊殺後用剩餘時間收割。
