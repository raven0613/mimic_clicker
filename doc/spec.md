# 寶箱偽裝者遊戲企劃書

## 1. 專案概述

> 在限時內打爆不斷流過的寶箱，找出唯一混在其中的偽裝 Jackpot；一旦揭穿，它就會活過來滿場逃跑——追上它，打爆它，拿走本局最大獎。

### 遊戲定位

一款以「持續敲擊寶箱、尋找偽裝頭獎、短局反覆成長」為核心的 Active Incremental / Clicker 遊戲。

玩家在限時內攻擊不斷由上往下緩慢流動的寶箱卡牌，盡可能打破更多寶箱、取得金錢與局內裝備，並從中找出每局唯一的「偽裝 Jackpot」。

普通寶箱即使流出場外也不會造成直接懲罰，只代表玩家錯過該目標與它可能帶來的收益。

偽裝 Jackpot 則會混入普通寶箱之中，以不同寶箱外皮偽裝。若玩家沒能在它流出場前揭穿，它會在短暫等待後換一個外皮重新混入場中，且每次重新出現的間隔逐漸增加。

當 Jackpot 的偽裝外殼被打破後，它會現出真身並開始在場地中高速移動，以可讀的直線路徑撞牆反彈，最後往下方出口逃走。玩家必須在它逃脫前追上並擊破，才能取得本局最大獎勵。

## 2. 核心體驗目標

遊戲希望提供以下節奏：

1. 平常大部分時間可以無腦、舒服地敲擊寶箱。
2. 玩家偶爾會因高價值裝備、效果卡或可疑行為而改變目標。
3. 每局都有一個明確的 Jackpot 懸念。
4. 玩家不需要仔細推理也能正常玩，但注意到偽裝者的細微破綻可以提高效率。
5. Jackpot 現形後，操作強度突然提升，形成短時間追逐高潮。
6. 一局結束後快速結算、購買永久升級並立即再開一局。
7. 長期形成「再打一場就能再升一級／再抓一次 Jackpot」的循環。

核心節奏可概括為：

> 掃箱 → 找可疑目標 → 揭穿偽裝 → 追殺 Jackpot → 大量噴獎 → 結算升級 → 再來一局

## 3. 單局流程

### 3.1 開局

- 玩家帶著永久主武器進場。
- 開始固定時間倒數。
- 初版只有一個關卡，場地依各寶箱怪的生成權重，持續生成所有已解鎖種類。
- 寶箱會從上方向下緩慢移動。
- 普通寶箱移出場外沒有直接懲罰。

### 3.2 普通掃場階段

玩家在場中自由挑選寶箱攻擊。

主要目標包含：

- 普通寶箱：提供基本金錢與隨機掉落。
- 高級寶箱：較硬，但內部收益更高。
- 身上插有高稀有裝備卡的寶箱：明確的高價值目標。
- 帶效果卡的寶箱：擊破後觸發落雷等掃場或資源效果。
- 偽裝 Jackpot：外觀看似普通寶箱，但會有極輕微的行為破綻。

玩家的普通決策應維持非常簡單：

> 打脆箱找 Jackpot、打肥箱拿好東西、打效果箱延長或加速本局。

### 3.3 Jackpot 揭露

當玩家打破偽裝 Jackpot 的外殼後：

- Jackpot 顯示真身。
- 取得獨立的 Jackpot 血量。
- 進入高速追逐狀態，此時才顯示並啟動 Jackpot 倒數條。
- 以帶有規律的直線路徑移動，撞牆時依合理角度反彈。
- 只使用微幅旋轉來表現動勢，不做持續翻滾。
- Jackpot 倒數耗盡時，先在原地短促抖動僵直，再由當下位置垂直向下逃走。

Jackpot 現形時可搭配：

- 短暫畫面定格。
- 特殊音效。
- 卡框或背景視覺變化。
- 向上或側邊彈開一段距離。
- 0.5～1 秒短暫控制效果，讓玩家有反應時間。

### 3.4 Jackpot 結果

#### 擊破成功

- Jackpot 使用與普通寶箱相同的金幣噴灑與收集流程，但以更高且有上限的視覺金幣數量表現大量噴獎。
- 高機率或保證掉落高稀有裝備。
- 可額外掉落特殊局外素材。
- 本局 Jackpot 不再生成。

#### 逃脫

- Jackpot 從下方離場。
- 不額外扣除主倒數時間。
- 玩家只是失去本局最大獎。
- 若 Jackpot 倒數先耗盡，普通遊戲可以持續至主倒數結束。
- 若主倒數在追逐中先耗盡，Jackpot 仍須完成「原地抖動僵直 → 垂直向下逃走」，之後才進入結算。

## 4. 偽裝 Jackpot 系統

### 4.1 基本規則

- 每局只有一個 Jackpot 實體。
- Jackpot 的偽裝池必須與目前關卡實際可能生成的寶箱怪種類一致。
- 它以普通寶箱的形式混入正常寶箱流。
- 玩家若沒有在它離場前揭穿，它會暫時離場。
- 經過一段等待時間後，Jackpot 會換一個隨機外皮再次混入場中。
- 每次未揭露就流走後，重返間隔逐漸增加，越晚抓到，本局剩餘捕捉機會越少。
- Jackpot 真正被擊殺後，本局不再重新生成。
- Jackpot 偽裝進場時不顯示額外時間條；只有外殼被打破、開始追逐後，才顯示與主倒數有明顯區別的 Jackpot 倒數條。
- 主倒數或 Jackpot 倒數任一條先耗盡，都會終止本次捕獲機會。
- Jackpot 獎勵以目前關卡可生成寶箱怪的最高收益為基準，再依 Jackpot config 放大，不使用完全固定的跨進度獎勵。

### 4.2 換皮的目的

換皮的主要目的：

- 避免玩家第一次辨認後，之後只需固定追同一張卡。
- 保留每一輪重新辨認的懸念。
- 讓新解鎖寶箱外皮同時增加偽裝池內容。
- 強化「同一隻生物會換殼混回來」的角色感。

### 4.3 身份連續性

即使外皮改變，Jackpot 應保留少量固定性格／破綻，讓玩家感覺它仍然是同一隻生物。

例如：

- 特定節奏的輕微抖動。
- 鄰近寶箱被攻擊時稍微縮一下。
- 游標靠近時偶爾停頓。
- 偶爾閃過特殊色像素。
- 接近離場時出現短促異常動作。
- 固定的小音效或影子特徵。

### 4.4 破綻原則

破綻不能變成必須掌握的推理規則。

目標是：

- 新手：無腦大量打箱，也有機會自然找到 Jackpot。
- 熟練玩家：注意細節後能提高找到 Jackpot 的效率。

不要讓每輪固定使用完全相同動畫，以免變成單純 UI 標記。

可使用「固定性格 + 隨機破綻」：

- 固定性格：每次都有一個小反應。
- 隨機破綻：每輪再抽 1～2 個額外行為。

### 4.5 真身追逐與退場

- Jackpot 在兩次碰牆之間維持可讀的直線移動，不無理由頻繁隨機轉向。
- 撞牆時依牆面法線反射速度方向；只允許極小且有上限的角度修正，避免完全水平、垂直或無限重複路徑。
- 追逐旋轉僅為微幅傾斜，最大角度、回正速度與碰撞偏移皆由 config 管理。
- 進入倒數耗盡退場後，Jackpot 立即停止受擊，在原地做短促抖動僵直。
- 僵直完成後鎖定當下水平位置、忽略側牆碰撞，直線向畫面下方離場。
- Jackpot 倒數先耗盡時，只結束 Jackpot 捕獲，主倒數與普通掃場繼續。
- 主倒數先耗盡時，立即禁止全部戰鬥操作，待 Jackpot 完成相同退場後進入結算。

## 5. 寶箱流動

### 5.1 普通寶箱

- 從場地上方向下緩慢流動（上到下20秒）。
- 離場不扣血、不扣時間。
- 離場只代表玩家錯過該寶箱及其收益。
- 普通寶箱移動速度應足夠慢，避免變成純反應型遊戲。

### 5.2 受擊反應

寶箱被攻擊時，應有明確但低成本的卡牌動態：

- 手動點擊成功造成攻擊時，在實際游標點擊位置播放 `effects/hit.png` 打擊特效；效果卡傷害不播放此手動點擊特效。
- 同一實體接受手動或未來武器傷害的最短間隔讀取 `combatConfig.minimumWeaponDamageIntervalPerTargetMs`；間隔尚未結束的點擊不造成傷害，也不觸發打擊特效、閃白、抖動、裂紋或其他受擊反應。
- 輕微抖動。
- 卡片後仰。
- 橫向偏移。
- 短暫停止下滑。
- 依剩餘血量比例逐步增加裂紋。
- 重擊時可往上彈一小段。

#### 裂紋階段

裂紋只是受損程度的視覺提示，不改變傷害、碰撞、點擊範圍、移動、收益或其他戰鬥規則。階段以「目前血量 ÷ 該外觀的最大血量」判定，初始門檻如下：

| 剩餘血量比例            | 外觀階段         |
| ----------------------- | ---------------- |
| 大於 70%                | 完整，沒有裂紋   |
| 大於 35% 且小於等於 70% | 輕微裂痕         |
| 大於 0% 且小於等於 35%  | 明顯裂縫         |
| 0%                      | 立即進入擊殺破碎 |

- `70%` 與 `35%` 必須由具名 config 管理，不得散落在受擊事件或 Pixi 顯示程式中。
- 單次攻擊跨越多個門檻時，直接顯示攻擊後血量所對應的最深階段，不依序播放已跳過的階段。
- 輕微裂痕使用少量、清楚但不搶畫面的程序式裂紋。
- 明顯裂縫必須沿用並延伸同一組輕微裂痕，不可整組換位；可增加少量分支及裂縫兩側的細微錯位感，但卡牌仍維持完整輪廓，不提前出現可分離碎片。
- 明顯裂縫的視覺錯位上限初始為 `2 px`，並由 config 管理；死亡前不可呈現接近破碎動畫的位移量。
- 裂紋使用三組預設圖樣變體。每張卡生成時選定其中一組並固定使用，後續受擊只延伸該圖樣，避免裂紋位置跳動，也降低大量同款寶箱完全相同的重複感。
- 初版 `normal` 會在一次非致死攻擊後進入輕微裂痕，再於下一次攻擊直接破碎；裂紋只是視覺強化，不為了讓它停留在明顯裂縫階段而修改血量或武器傷害。
- 可受擊的一般寶箱與 Jackpot 偽裝外殼都依各自外觀的最大血量顯示裂紋。偽裝外殼被擊破並切換 Jackpot 真身時，裂紋重置為完整狀態，再依 Jackpot 真身血量重新累積。
- 結算背景中的裝飾寶箱不可受擊，也不顯示裂紋。
- 擊殺成立時立即執行既有破碎與獎勵流程，不為了展示最後一段裂紋而延後死亡結算。

受擊反應的目的：

- 提供打擊感。
- 避免靜態卡牌像純 UI。
- 讓玩家在連續攻擊同一目標時有「黏著」感。

寶箱受擊時低機率觸發向上逃跑：

- 只剩 15% HP 時低機率觸發
- 一開始先有 0.2～0.4 秒「嚇到」的預備動作，再開始往上跑。
- Z 軸拉到最前
- 路線基本是直線
- 1～3 下通常能補死
- 沒有第二時間條
- 往上消失後就是真的沒了

#### 和 Jackpot 受擊反應差異

普通箱：
↓ 緩慢流動
瀕死偶爾 → ↑ 慢速逃跑

偽裝 Jackpot：
↓ 假裝普通
被揭露 → ↔↗↘ 高速直線反彈
Escape Bar 結束 → ↓↓↓ 正式逃離

限制：

- 同時最多 1～2 隻普通逃跑箱
- 觸發率低
- 不左右蛇行，頂多卡片本身抖動
- 不做大量粒子
- 不給巨大 UI

### 5.3 場地排列

採用無固定軌道的受限隨機排列：

- 水平位置在場地安全範圍內連續分布，不切成可辨認的垂直路線。
- 卡牌應呈現自然散落感，允許少量重疊，但不得遮住過多可點擊區域。
- 生成時從多個候選位置選擇與現有卡牌重疊最少者。
- 若暫時沒有位置符合最大重疊限制，短暫延後生成，不強制塞入嚴重重疊的位置。
- 場地安全邊距、最大重疊比例、候選次數與重試間隔都由 config 管理。
- Jackpot 真身可脫離普通流動規則滿場移動，並固定顯示在所有普通寶箱之上。

### 5.4 擊破噴幣與本局收益回饋

每一隻普通寶箱怪與 Jackpot 被擊破時，都使用實際金幣 Sprite 取代原本浮在寶箱頭上的 `+收益` 文字與圓形獎勵粒子；死亡破碎效果仍可同時播放。

金幣演出流程：

1. 寶箱死亡位置向外拋物線噴出一批金幣，飛行時循環播放 `coin/gold_coin_flip` 的翻轉幀。
2. 每顆金幣在死亡位置下方的局部落地帶碰地反彈 2～3 次，不使用畫面底部作為所有金幣共用地面。
3. 最後一次落地後，金幣停在 `gold_coin_flip` 的最後一幀並短暫留在地上。
4. 收集開始時切換成 `coin/gold_coin_idle` 姿態，各金幣以短促錯開的弧線集中飛向右上角本局收益區。
5. 同一批金幣開始抵達後，本局收益數字以 0～9 向上滾動的拉霸式動態追向新的累計金額。

規則：

- 右上角金錢區顯示本局累計收益，不顯示玩家局外總金幣。
- 收益、擊破數及後續結算在死亡成立時立即生效，不等待金幣動畫或數字滾動完成。
- 顯示用金幣數量只表達收益強度，不等於實際獎勵數值；收益越高可噴出越多金幣，但必須設有上限。
- Jackpot 沿用同一套動畫語言，以更多視覺金幣表現最高價值，不另建平行噴獎系統。
- 連續擊破時，各批金幣可同時存在；本局收益數字只能向最新的顯示目標前進，不得倒退或漏算。
- 回合結束或場景清理可中斷未完成的純視覺動畫，但不得影響已取得的實際收益。
- 翻轉速度、顯示尺寸、視覺數量映射、散射、初速、重力、局部落地範圍、反彈次數與係數、停留、收集弧線、錯開時間及數字滾動節奏皆由 config 管理。

## 6. 寶箱種類

### 普通寶箱

- 基礎血量。
- 基礎金錢與掉落。

### 高級寶箱

- 血量較高。
- 內部收益與稀有度較高。
- 更可能帶高稀有裝備。

初版以 `normal`、`rare1`、`rare2` 三種寶箱怪建立這個強度階梯；詳細解鎖與生成規則見[初版單關卡與前三局解鎖規格](./initial_release.md)。

### 帶裝備卡&效果卡寶箱

- 外部可見一張或多張效果卡／裝備卡，以同一組固定扇形插在寶箱右上角；兩類卡不得各自建立互相重疊的排列。
- 玩家一眼即可判斷其價值。
- 效果卡與裝備先形成同一候選集合，再公平裁切到攜帶者的共用容量；同一攜帶者不得用重複內容填滿容量。
- Jackpot 偽裝沿用目前外皮容量；真身依 Jackpot config 從效果卡與裝備的共同內容池保證選取，不另建平行選卡系統。
- 擊破時效果卡必定觸發；可見裝備則各自依裝備 config 判定是否成功掉落，不採用攻擊鬆動值。

若有效果卡擊破時觸發特殊效果，例如：

- 落雷。
- 隕石。
- 炸彈。
- 冰凍。
- 時鐘。
- 其他未來特殊效果。

效果卡的共通附著、外觀與觸發規則，以及初版落雷與隕石的完整行為見[效果卡規格](./effect_cards.md)。

## 7. 裝備卡系統

裝備是只在目前單局生效的即時強化。本次規則如下：

- 可見裝備在攜帶者被擊破或 Jackpot 偽裝破殼時，依 config 各自判定掉落；延後裝備鬆動／震落。
- 每個可戰鬥攜帶者還可有最多一件不顯示、也不占外掛容量的內部裝備；是否存在與稀有度分布依 config 決定。
- 成功掉落後先原子保留通用裝備槽，再播放比同事件金幣稍晚抵達的收集動畫；抵達槽位才生效，滿槽則飛向尚未啟用的背包入口並維持無效。
- 初版內容為可疊加固定武器傷害的 `sword`，以及累積有效手動命中、按已裝備數量依序追加傷害的 `ring`。
- 所有局內裝備與待結算效果在回合收尾清除；本次不處理裝備管理、出售、素材轉換或跨局保存。

完整抽選、Jackpot、槽位保留、動畫、Sword、Ring、config 與驗證規則見[裝備卡與局內裝備系統規格](./equipment_system.md)。

## 8. 寶箱內部掉落

本次內部隱藏內容只處理裝備：每個可戰鬥攜帶者在建立時依 config 產生零或一件，擊破／破殼時才揭露並直接加入裝備獎勵批次。它不占外掛容量，且排除同一攜帶者已顯示的裝備 id。詳細規則見[裝備卡與局內裝備系統規格](./equipment_system.md)。

---

## 9. 效果卡

效果卡是附著在寶箱外部、可在擊破前辨識的局內目標。多張效果卡在同一寶箱擊破事件中一起開始各自的效果流程；效果卡與裝備卡共存時，效果發動與裝備／金錢噴散可以並行。初版包含落雷與 `SSR` 隕石：落雷在前搖完成後隨機選擇有效怪物並立即造成一次底端範圍傷害；隕石先在 canvas 內隨機決定落點，再從右上方畫面外往左下飛入，落地時造成一次爆炸範圍傷害。隕石傷害正方形以爆炸實際顯示寬度乘上可調倍率推導，倍率預設為 `1`；兩種效果都允許依共通前搖流程連鎖觸發。

效果卡的附著、顯示、觸發、落雷與隕石完整行為，以及後續炸彈、冰凍與時鐘方向，統一見[效果卡規格](./effect_cards.md)。

## 10. 主武器與攻擊

### 10.1 手動攻擊

- 玩家以滑鼠點擊寶箱造成傷害。
- 武器傷害間隔由每個可受擊實體獨立保存；攻擊其他寶箱不會延長原目標的間隔，第一擊立即生效，距離上次有效武器傷害達到 config 間隔時可再次受傷。
- 落雷、隕石及其他效果卡傷害不受武器傷害間隔限制，避免同時發動的效果互相取消；它們仍與武器攻擊共用傷害、死亡、收益及 Jackpot 結算入口。
- 打破 Jackpot 偽裝外殼時，同一 runtime 實體剩餘的武器傷害間隔延續至真身，不因換圖、重設血量或建立真身外掛卡而清除。
- 有效手動攻擊在實際點擊位置播放 `effects/hit.png`：`1750 × 218` 水平圖帶切成 `5` 幀，每幀 `350 × 218`；實際顯示寬高分別為單格寬高乘上正數 `manualHitEffect.displayScale`，並以 `180 ms` 播放一次後清除。顯示比例只改變視覺大小，不得改動來源或切幀尺寸。
- 點擊特效位於世界特效層，必須能在該次攻擊同時擊破並移除寶箱後完成播放；不跟隨寶箱後續 transform，也不攔截輸入。
- 主要回饋來自：點擊特效、卡牌晃動、裂紋、打擊音效、掉錢與裝備效果。

### 10.2 懸停自動攻擊

局外可解鎖：

- 游標停留在寶箱上時，每隔 X 秒自動攻擊一次。
- 手動點擊仍然正常計算。
- 永久升級可以縮短自動攻擊間隔。

目的：

- 降低長時間點擊疲勞。
- 保留手動點擊的主動加速感。

自動攻擊不能強到完全取代玩家：

- 可設定頻率上限。
- 手動攻擊仍明顯提高輸出。
- 某些裝備與重擊效果只由手動攻擊觸發。

### 10.3 未來武器差異

不同武器不只提升傷害，也可帶有不同攻擊特性，例如：

- 大錘：單擊高傷。
- 雙刃：一次兩段傷害。
- 鑿子：對高防寶箱更有效。
- 掉寶錘：提高可見裝備成功掉落率。
- 追蹤型武器：更容易攻擊 Jackpot。

## 11. 局內成長

玩家在一局內透過：

- 撿到裝備。
- 自動裝備／疊加裝備。
- 取得效果卡。
- 延長時間。
- 建立更高的掃場與追殺效率。

希望形成：

> 前段普通 → 中段裝備逐漸成形 → Jackpot 出現時火力爆發 → 擊殺後用剩餘時間收割。
