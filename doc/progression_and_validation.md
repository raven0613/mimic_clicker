# 局外成長、內容與驗證規格

本文件承接 [spec.md](./spec.md) 的核心玩法，定義局外經濟、升級、結算、長期內容、美術回饋、原型驗證與初版 Demo 範圍。

## 12. 局外經濟

### 12.1 金幣

主要來源：

- 寶箱直接掉落。
- 一局結束後裝備出售。
- 通關或結算獎勵。

用途：

- 主武器一般升級。
- 自動攻擊頻率。
- 起始時間。
- 一般效果卡強化。
- 基礎掉寶與收益強化。

### 12.2 特殊素材

高階永久成長貨幣。

主要來源：

- 高稀有裝備結算出售時額外產出。
- Jackpot。
- Boss / 章節里程碑。
- 特殊成就。
- 金幣兌換。

金幣應可換特殊素材，避免永久成長過度依賴隨機掉落。

但兌換不宜完全無限制：

- 可設定價格較高。
- 每場／每章有限量。
- 保持特殊素材的稀有感。

## 13. 局外升級方向

### 主武器

- 傷害。
- 武器階級。
- 重擊。
- 多段傷害。
- 特殊攻擊型態。
- 對 Jackpot 額外效果。

### 自動攻擊

- 解鎖懸停自動攻擊。
- 降低攻擊間隔。
- 換目標時保留部分進度。
- 手動攻擊降低下一次自動攻擊等待。
- 自動重擊機率。

### 時間

- 起始時間。
- 時鐘加時效果。
- 單局加時上限。
- 時間低時的輕度補救能力。

### 效果卡

炸彈：

- 傷害。
- 範圍。
- 連鎖。
- 額外金錢收益。

冰凍：

- 持續時間。
- 減速比例。
- Jackpot 額外控制效果。

時鐘：

- 加秒數量。
- 特殊版本。
- 低血壓力下的強化。

### 掉寶與幸運

不要只用模糊的 Luck 數值。

拆分為：

- 裝備掉落率。
- 高稀有度機率。
- 掉落升階機率。
- 寶箱附帶裝備率。
- Jackpot 特殊獎勵率。
- 連續未出高稀有度時的保底值。

### 裝備與槽位

- 裝備槽擴充。
- 暫存區容量。
- 裝備震落效率。
- 高稀有裝備出售素材量。
- 自動裝備規則。

### Jackpot / 偽裝相關

可作為高階升級：

- 首次重返間隔縮短。
- Jackpot 現形後短暫減速。
- Jackpot 被命中後更久的受擊停頓。
- 擊殺 Jackpot 額外金錢。

## 14. 一局結算

一局結束後應非常快速。

流程：

1. 所有局內裝備自動出售。
2. 高稀有裝備額外轉換特殊素材。
3. 顯示本局金錢、擊破數、Jackpot 結果。
4. 結果與出售完成後，若本局達成新寶箱怪解鎖，顯示解鎖提示。
5. 玩家回到可主動選擇購買局外升級或再次開始的介面。

本局正式結束後：

- React UI 以輕微高斯模糊覆蓋仍在運作的全螢幕戰鬥場地。
- 所有戰鬥輸入與收益計算停用，玩家只能操作前景 UI。
- 背景沿用同一生成器進入裝飾模式，繼續生成所有已解鎖寶箱怪，但不生成 Jackpot，也不附帶裝備卡或效果卡。
- 裝飾寶箱不具有可互動血量、收益、掉落或統計；下一局開始前必須清除。

避免：

- 強制整理背包。
- 每局長時間比較裝備。
- 大量結算 UI。
- 多層選單打斷「再一局」節奏。

## 15. 長期內容結構

每達成一個小目標（該目標可能每一兩場就能達成）：

- 解鎖新的寶箱怪種類與外皮。
- 解鎖新的裝備。
- 解鎖新的效果卡。
- 加入更高階寶箱。
- 擴充 Jackpot 可使用的偽裝外皮池。

寶箱怪一旦解鎖，會同時加入普通生成池與 Jackpot 偽裝池；初版固定順序見[初版單關卡與前三局解鎖規格](./initial_release.md)。

未來擴充時可加入不同主題牌庫，例如：

- 詛咒寶箱。
- 機械保險箱。

## 16. 視覺與美術方向

主要美術可採：

- 靜態像素風卡牌。
- 少色或低動畫成本。
- 以整張卡片的位移、抖動、縮放、裂紋、閃光創造打擊感。

普通寶箱：

- 緩慢向下流動。
- 被打時小幅移動。
- 裂痕隨傷害增加。

Jackpot：

- 真身現形後才大量移動。
- 使用整張卡移動、彈跳、微幅旋轉與殘影即可。
- 不需要大量角色骨架動畫。

Jackpot 的視覺賣點應是：

> 一堆規律流動的靜態寶箱裡，突然有一張「活了起來」。

動畫共通原則：

- 預備短、命中清楚、收尾快，不堆疊無意義的長動畫。
- 傷害、死亡與獎勵結算不等待純視覺動畫播完。
- 動畫必須能被死亡、退場或更高優先狀態中斷。
- 受擊閃白、卡牌抖動、噴獎與破碎等幅度、速度、數量、時間及緩動參數一律由 config 管理。
- 死亡破碎優先使用現有 Mimic 圖切片後飛散、旋轉、下墜與淡出，不要求額外逐幀美術。

## 17. 音效與回饋

普通攻擊：

- 清脆撞擊。
- 金屬／木材依寶箱類型變化。
- 裂紋增加時音效逐漸變重。

裝備震落：

- 高辨識度的卡牌彈出聲。
- 裝備旋轉飛出。
- 高稀有度可有特殊音效。

Jackpot：

- 揭露瞬間音樂或音效切換。
- 逃跑時有明確節奏提示。
- 接近出口時強化警示。
- 擊殺後使用全局最強的噴獎音效與畫面。

## 18. 原型優先驗證項目

第一版原型不需要完整內容。

### 18.1 驗證類型與邊界

初版使用三層驗證，三者不能互相取代：

1. **確定性核心測試**：驗證公式、狀態轉換、結算、解鎖、存檔與不變條件。
2. **批次平衡模擬**：使用固定 seed 與玩家操作模型，觀察大量單局的分布與趨勢。
3. **人工體感檢查**：確認點擊、辨識、動畫節奏與 Jackpot 高潮是否符合設計目標。

自動化測試只涵蓋遊戲核心邏輯，不測 React 元件排版、SCSS、模糊效果或純視覺動畫。若 UI 中出現會影響結果的計算，應將計算移至 service，再針對 service 行為測試。

批次模擬可以判斷數值是否落在設定的目標區間，但不能證明遊戲好玩。點擊是否舒服、動畫是否有力、資訊是否清楚，仍必須由人工遊玩確認。

### 18.2 初版核心平衡驗證閘門

#### 觸發範圍

變更下列任一內容時，必須執行受影響的核心測試與平衡模擬：

- 玩家攻擊力、攻擊頻率或其他直接影響輸出的數值。
- 寶箱怪血量、收益、生成權重、移動速度或生成間隔。
- 主倒數、Jackpot 血量、追逐時間、移動速度、獎勵或重返規則。
- 會改變擊殺數、收益、捕獲機會或進度速度的核心規則。
- 新增寶箱怪、解鎖階段或可生成內容。

只修改文字、SCSS 或不影響判定與時間的純視覺表現時，不觸發批次平衡模擬，但仍需進行相應人工檢查。

#### 最小案例矩陣

每次模擬至少涵蓋所有受影響的解鎖階段與操作模型：

| 維度 | 初版必要案例 |
| --- | --- |
| 寶箱怪生成池 | 只有 `normal`；`normal + rare1`；`normal + rare1 + rare2` |
| 玩家操作模型 | 較慢點擊；目標點擊速度；較快點擊 |
| 點擊命中模型 | 較低命中率；目標命中率；較高命中率 |
| Jackpot 路徑 | 未揭露；揭露後擊殺；揭露後逃脫；主倒數在追逐中先耗盡 |

- 操作頻率、命中率、樣本數與固定 seed 清單必須使用具名 config，不可散落在測試內。
- 只需執行受變更影響的組合，但不得略過任何受影響的解鎖階段。
- 隨機模擬必須可重複；相同 config、seed 與操作模型應產生相同結果。

#### 必要指標

模擬至少輸出：

- 各寶箱怪平均與分位擊破次數或擊破時間。
- 各寶箱怪實際生成占比、每局生成數與每局擊殺數。
- 生成位置被拒絕與延後重試的比例。
- 每局普通收益、Jackpot 收益與總收益分布。
- Jackpot 每局可揭露機會、揭露率、擊殺率與逃脫率。
- 不同解鎖階段的平均收益與難度變化比例。
- 主倒數結束時的場上狀態與 Jackpot 結果分布。

平均值之外，至少保留能看出極端結果的分位資訊，避免少數異常局被平均值掩蓋。

#### 通過條件

平衡變更必須同時符合：

1. 所有受影響的確定性核心測試通過。
2. `rare2` 的血量與基礎收益高於 `rare1`，`rare1` 高於 `normal`。
3. 寶箱怪實際生成占比、每局擊殺數、總收益與 Jackpot 成功率落在具名平衡目標 config 的允許區間。
4. Jackpot 獎勵隨目前生成池的最高寶箱收益成長，且不會因新增低階寶箱而下降。
5. 場地排列的拒絕與延後生成比例未超過具名目標上限，不會因無可用位置長時間停止生成。
6. 任一必要案例都不能出現 Jackpot 無法進入、無法結束、重複結算或本局無法收尾。
7. 受影響的人工體感項目已實際確認，沒有用模擬結果代替操作與視覺判斷。

若具名目標區間尚未建立，該平衡項目只能標記為「待校準」，不得宣告完成。第一版允許先建立暫定目標，之後依實際遊玩調整 config；調整後必須重新執行受影響案例。

#### 模擬報告

每次平衡驗證結果至少記錄：

- 使用的 config 版本或數值摘要。
- 固定 seed 集合與每個案例的樣本數。
- 實際執行的案例矩陣。
- 必要指標、目標區間與通過／失敗結果。
- 未通過項目及後續調整方向。

報告只需保存足以重現與判斷的摘要，不保存每一局的完整逐幀資料。

### 18.3 人工體感優先項目

最優先驗證：

#### A. 普通箱是否能連續打 30～60 秒仍然舒服

需要測：

- 移動速度。
- 受擊停頓。
- 打擊動畫。
- 破碎頻率。
- 金錢噴出。

#### B. Jackpot 現形後是否真的形成高潮

需要測：

- 移動速度。
- 變向頻率。
- 逃跑時間。
- 點擊判定大小。
- 被打後減速／停頓。
- 擊殺所需時間。

#### C. 偽裝破綻是否「看得到但不必看」

需要測：

- 新手能否靠無腦掃場找到 Jackpot。
- 熟練玩家是否能用破綻提高成功率。
- 破綻是否過度明顯。

#### D. 換皮重返是否會讓玩家覺得合理

需要測：

- 玩家是否理解是同一隻 Jackpot。
- 是否會產生「反正下一個還會來」的消極策略。
- 重返間隔需要增加多少。

#### E. 裝備震落是否增加樂趣

需要測：

- 鬆動視覺是否直覺。
- 是否會促使玩家過度切換目標。
- 震落成功是否夠爽。
- 震落後玩家是否仍願意打破原寶箱。

#### F. 結算是否足夠短

理想狀態：

- 幾秒內理解收益。
- 幾秒內買完升級。
- 馬上再開下一局。

### 18.4 第一階段暫定平衡報告

本次第一階段使用 `initial-vertical-slice-v1` config 與 12 個固定 seed，執行以下完整矩陣：

- 3 種解鎖生成池。
- 3 種點擊速度。
- 3 種命中率。
- 4 種 Jackpot 路徑。
- 合計 1,296 個可重複案例。

暫定結果摘要：

| 指標 | 結果 | 暫定目標 | 狀態 |
| --- | ---: | ---: | --- |
| 最大排列拒絕率 | 0.0% | 不高於 20% | 通過 |
| 最大生成占比偏差 | 2.3% | 不高於 8% | 通過 |
| 目標操作模型平均擊破數 | 53.0 | 每局 42～55 | 通過 |
| 目標操作模型指定追殺的 Jackpot 擊破率 | 100% | 95%～100% | 通過 |
| 只有 `normal` 的平均總收益 | 259.9 | 隨階段單調上升 | 通過 |
| 加入 `rare1` 的平均總收益 | 354.9 | 高於前一階段 | 通過 |
| 三種全解鎖的平均總收益 | 424.3 | 高於前一階段 | 通過 |
| 無法完成本局的案例 | 0 | 必須為 0 | 通過 |

報告由 `npm run test:balance` 依 `src/configs/balanceSimulationConfig.ts` 產生；攻擊力、血量、收益、生成權重與時間均讀取正式 config。模擬中的操作模型用來比較數值趨勢，不模擬人類游標移動、目標辨識延遲或動畫造成的注意力成本。

因此目前只能判定暫定數值通過自動化閘門。受擊感、卡牌辨識、Jackpot 追逐高潮、結算速度與 30～60 秒連續點擊舒適度仍標記為「待人工體感確認」；完成實際遊玩後若調整任何結果相關 config，必須重新執行相同受影響矩陣。

## 20. 核心設計原則

1. 普通階段必須能無腦玩。
2. Jackpot 揭露前的行為細節只能提供優勢，不能成為必修。
3. Jackpot 必須是每局最大的期待與操作高潮。
4. 裝備、效果卡與高級寶箱只能作為中小型誘惑，不與 Jackpot 搶主角地位。
5. 寶箱離場代表錯過機會，不代表直接受傷。
6. Jackpot 逃跑代表失去最大獎，不額外雙重懲罰。
7. 局內裝備提供即時變強感，局外貨幣提供穩定長期進度。
8. 每一局應短、結算應快、下一局應立即開始。
9. 任何新系統都必須先回答：它是否會讓玩家停止無腦敲箱？
10. 宣傳與視覺必須突出「普通卡很規律，只有 Jackpot 突然活起來」這個反差。
