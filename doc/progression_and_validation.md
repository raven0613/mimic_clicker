# 局外成長、內容與驗證規格

本文件承接 [spec.md](./spec.md) 的核心玩法，定義局外經濟、結算、長期內容、美術回饋、原型驗證與初版 Demo 範圍。目前採用的升級等級與購買規則見[永久升級規格](./permanent_upgrades.md)，清場頻率、低密度續戰補場與耐久錨點的專屬指標見[連鎖清場與低密度續戰補場規格](./chain_clear_and_refill.md)，裝備端到端與自動出售規則見[裝備卡與局內裝備系統規格](./equipment_system.md)。

## 12. 局外經濟

### 12.1 金幣

主要來源：

- 寶箱直接掉落。
- 一局結束後自動出售本局成功取得的裝備。
- 通關或結算獎勵。

用途：

- 解鎖懸停自動攻擊，以及自動攻擊間隔 1～3 級。
- 一次性的「裝備槽 III」里程碑。

### 12.2 特殊素材

特殊素材只保留為後續版本候選，不是目前兩條永久升級的購買條件。初版不建立素材來源、金幣兌換、用途、UI 或存檔預設欄位；等確定有金幣無法承擔的高階成長需求時，再另行規格化。

---

## 13. 目前永久升級範圍

目前採用兩條短成長線：

1. 解鎖懸停自動攻擊後，自動攻擊間隔 1～3 級。
2. 一次性的「裝備槽 III」里程碑，使基礎 2 格在下一局增加為 3 格。

兩條線只使用金幣，不做互斥分支或總投資門檻。自動攻擊線只有「先解鎖、再縮短間隔」的線性前置；第三槽沒有跨線前置。等級、戰鬥套用、未來第 4 槽擴充與驗證規則統一見[永久升級規格](./permanent_upgrades.md)。

主武器基礎攻擊力固定讀取 `combatConfig.initialWeaponDamage`，不提供微幅永久攻擊力升級。未來若加入階段性新主武器，必須另行規格化足以形成明顯門檻變化的購買、價格、呈現與存檔，不把已移除的小幅傷害等級塞回目前兩條成長線。

目前也不加入手動攻速、個別裝備卡、裝備效果分類、可見裝備掉落／回收、起始時間、效果卡、Luck／掉寶、Jackpot 或特殊素材升級。這些項目不得留在初版升級 UI、購買 config 或存檔預設值中形成未完成節點。

## 14. 一局結算

一局結束後應非常快速。裝備只存在單局內，回合收尾時全部自動出售為金幣，不讓玩家逐件選擇是否保留或出售；初版不做素材轉換。

本次流程：

1. 主倒數結束後停止新的戰鬥結果，立即凍結戰鬥收益與成功取得裝備的出售快照；已裝備、已進背包及倒數前成功掉落但仍在飛行中的裝備都計入。若 Jackpot 正在逃跑，只等待既有退場，不再改變快照。
2. 在清除局內狀態前保留該不可變快照，取消純視覺飛行、槽位保留與待結算能力。
3. 依具名 config 計算裝備出售收益及本局總收益。
4. 將總收益、生涯局數、新解鎖與待展示提示作為一致進度寫入 IndexedDB；存檔成功後才揭示結算。
5. 先顯示戰鬥收益，再依 equipment id 合併快速顯示「名稱 × 數量」及乘算後小計，最後將出售收益併入本局總收益；不顯示單價。
6. 玩家可在短動畫期間點擊快轉；沒有裝備時略過出售區塊。揭示完成後才進入解鎖提示或可再次開始的介面。

普通出售使用穩定的「基礎價格 × 稀有度倍率」，不依單局收入百分比改價；平衡上另以 `裝備出售收益 ÷ 本局總收益` 驗證占比，使不同局長與解鎖階段仍可比較。初始價格、分組、快轉與顯示時序以[裝備結算自動出售](./equipment_system.md#9-結算自動出售)為準。

本局正式結束後，React UI 以輕微高斯模糊覆蓋仍在運作的全螢幕戰鬥場地；所有戰鬥輸入與收益計算停用，玩家只能操作前景 UI。
背景沿用同一生成器進入裝飾模式，繼續生成所有已解鎖寶箱怪，但不生成 Jackpot，也不附帶裝備卡或效果卡；裝飾寶箱不具戰鬥結果，下一局開始前必須清除。
結算不得強制整理背包、要求逐件比較裝備、堆疊大量 UI 或使用多層選單打斷「再一局」節奏。

## 15. 長期內容結構

每達成一個小目標（該目標可能每一兩場就能達成）：

- 解鎖新的寶箱怪種類與外皮。
- 解鎖新的裝備。
- 解鎖新的效果卡。
- 加入更高階寶箱。
- 擴充 Jackpot 可使用的偽裝外皮池。

寶箱怪一旦解鎖，會同時加入普通生成池與 Jackpot 偽裝池；初版固定順序見[初版單關卡與前三局解鎖規格](./initial_release.md)。

未來擴充時可加入不同主題牌庫，例如：

- 詛咒寶箱。
- 機械保險箱。

## 16. 視覺與美術方向

主要美術可採：

- 靜態像素風卡牌。
- 少色或低動畫成本。
- 以整張卡片的位移、抖動、縮放、裂紋、閃光創造打擊感。

普通寶箱：

- 緩慢向下流動。
- 被打時小幅移動。
- 裂痕隨傷害增加。

Jackpot：

- 真身現形後才大量移動。
- 使用整張卡移動、彈跳、微幅旋轉與殘影即可。
- 不需要大量角色骨架動畫。

Jackpot 的視覺賣點應是：

> 一堆規律流動的靜態寶箱裡，突然有一張「活了起來」。

動畫共通原則：

- 預備短、命中清楚、收尾快，不堆疊無意義的長動畫。
- 傷害、死亡與獎勵結算不等待純視覺動畫播完。
- 動畫原則上必須能被死亡、退場或更高優先狀態中斷；已排入佇列的 Ring 追加 hit 是明定例外，本局進行中即使原目標失效仍須完整播放純視覺段數，直到主倒數耗盡或回合收尾才取消。
- 受擊閃白、卡牌抖動、噴獎與破碎等幅度、速度、數量、時間及緩動參數一律由 config 管理。
- 手動點擊的 5 幀打擊特效只在該目標通過 `combatConfig.minimumWeaponDamageIntervalPerTargetMs` 並成功受傷時出現在實際點擊位置，總時間讀取 `animationConfig.manualHitEffect.animationDurationMs`；被間隔拒絕的點擊及效果卡傷害都不播放此特效。
- 死亡破碎優先使用現有 Mimic 圖切片後飛散、旋轉、下墜與淡出，不要求額外逐幀美術。
- 所有寶箱擊破都以翻轉金幣拋射、局部落地反彈、短暫停留及集中飛向本局收益 HUD 表現入帳，不再使用頭頂收益文字與圓形獎勵粒子。
- Jackpot 沿用相同金幣動畫語言並提高視覺數量，讓玩家能直接感受到收益級距，同時維持短促收尾。

## 17. 音效與回饋

普通攻擊：

- 清脆撞擊。
- 金屬／木材依寶箱類型變化。
- 裂紋增加時音效逐漸變重。

裝備掉落：

- 高辨識度的卡牌彈出聲。
- 裝備旋轉飛出。
- 高稀有度可有特殊音效。

Jackpot：

- 揭露瞬間音樂或音效切換。
- 逃跑時有明確節奏提示。
- 接近出口時強化警示。
- 擊殺後使用全局最強的噴獎音效與畫面。

## 18. 原型優先驗證項目

第一版原型不需要完整內容。

### 18.1 驗證類型與邊界

初版使用三層驗證，三者不能互相取代：

1. **確定性核心測試**：驗證公式、狀態轉換、結算、解鎖、存檔與不變條件。
2. **批次平衡模擬**：使用固定 seed 與玩家操作模型，觀察大量單局的分布與趨勢。
3. **人工體感檢查**：確認點擊、辨識、動畫節奏與 Jackpot 高潮是否符合設計目標。

自動化測試只涵蓋遊戲核心邏輯，不測 React 元件排版、SCSS、模糊效果或純視覺動畫。若 UI 中出現會影響結果的計算，應將計算移至 service，再針對 service 行為測試。

批次模擬可以判斷數值是否落在設定的目標區間，但不能證明遊戲好玩。點擊是否舒服、動畫是否有力、資訊是否清楚，仍必須由人工遊玩確認。

### 18.2 初版核心平衡驗證閘門

#### 觸發範圍

變更下列任一內容時，必須執行受影響的核心測試與平衡模擬：

- 玩家攻擊力、每目標武器傷害間隔、攻擊頻率或其他直接影響輸出的數值。
- 永久升級的效果值、價格、最高等級、前置條件或實際槽位解析規則。
- 寶箱怪血量、收益、生成權重、移動速度、生成間隔、場內填場區域、低密度／清場判定、續戰補場或填場終止規則。
- 主倒數、Jackpot 首次生成延遲、血量、追逐時間、移動速度、獎勵或重返規則。
- 效果卡附帶機率、傷害、道數／顆數、持續時間、傷害間隔、移動、範圍、目標規則、連鎖或其他會改變戰鬥結果的行為。
- 裝備附著／掉落／稀有度、槽位數、Sword 加成、Ring 門檻／倍率／固定間隔或其他會改變輸出的行為。
- 裝備出售基價、稀有度倍率、出售資格、分組或其他會改變結算入帳的規則。
- 會改變擊殺數、收益、捕獲機會或進度速度的核心規則。
- 新增寶箱怪、解鎖階段或可生成內容。

只修改文字、SCSS 或不影響判定與時間的純視覺表現時，不觸發批次平衡模擬，但仍需進行相應人工檢查。

階段式裂紋屬於純視覺表現。調整裂紋門檻、線條、透明度或最多 `2 px` 的錯位程度時，不重新執行平衡模擬；若同時改動寶箱血量、玩家傷害或其他會改變擊破結果的數值，仍必須依本節矩陣完成受影響的核心測試與平衡模擬。

#### 最小案例矩陣

每次模擬至少涵蓋所有受影響的解鎖階段與操作模型：

| 維度 | 初版必要案例 |
| --- | --- |
| 寶箱怪生成池 | 只有 `normal`；`normal + rare1`；`normal + rare1 + rare2` |
| 玩家操作模型 | 較慢點擊；目標點擊速度；較快點擊 |
| 點擊命中模型 | 較低命中率；目標命中率；較高命中率 |
| Jackpot 路徑 | 未揭露；揭露後擊殺；揭露後逃脫；主倒數在追逐中先耗盡 |
| 局內裝備 | 未裝備；單一裝備；重複同件；Sword 與 Ring 混裝 |
| 背包換裝模型 | 不主動換裝；Sword 優先；Ring 優先 |
| 永久升級 | 全部等級 0；自動攻擊解鎖與間隔各級；裝備槽 III；全部目前升級完成 |

- 操作頻率、命中率、樣本數與固定 seed 清單必須使用具名 config，不可散落在測試內。
- 只需執行受變更影響的組合，但不得略過任何受影響的解鎖階段。
- 隨機模擬必須可重複；相同 config、seed 與操作模型應產生相同結果。

#### 必要指標

模擬至少輸出：

- 各寶箱怪平均與分位擊破次數或擊破時間。
- 各寶箱怪實際生成占比、每局生成數與每局擊殺數。
- 各解鎖階段的開場／續戰填場數量、低密度觸發、真正清場與補場次數、補場前後有效目標數、未達 12 的短缺、空場持續時間，以及生成位置被拒絕與延後重試的比例。
- 每局普通收益、Jackpot 收益與總收益分布。
- 每局戰鬥收益、裝備出售收益、最終總收益，以及出售收益占最終總收益的比例；出售項目須能依 equipment id 與取得狀態追查。
- Jackpot 每局可揭露機會、揭露率、擊殺率與逃脫率。
- 各效果卡每局附帶數、觸發數、平均命中數、平均額外傷害、連鎖清除比例、完整清場率與最大連鎖深度。
- 各裝備每局可見／隱藏產生數、成功掉落數、裝備／背包數、換裝次數、平均啟用時間與平均額外傷害。
- 各永久升級案例的手動／自動有效命中數、傷害占比、實際槽位數與第三槽平均啟用時間。
- 各解鎖階段在不同操作模型下，累積金幣購買每一級所需局數的平均值與分位數。
- 不同解鎖階段的平均收益與難度變化比例。
- 主倒數結束時的場上狀態與 Jackpot 結果分布。

平均值之外，至少保留能看出極端結果的分位資訊，避免少數異常局被平均值掩蓋。

#### 通過條件

平衡變更必須同時符合：

1. 所有受影響的確定性核心測試通過。
2. `normal`、`rare1`、`rare2` 符合[連鎖清場與低密度續戰補場規格](./chain_clear_and_refill.md)的連鎖燃料、短補刀與耐久錨點傷害門檻，且血量與基礎收益維持逐階提高。
3. 寶箱怪實際生成占比、每局擊殺數、總收益與 Jackpot 成功率落在具名平衡目標 config 的允許區間；初版 `30` 秒局長下，目標操作配置的平均擊殺暫定為每局 `55～75` 隻，正式門檻必須存於 `balanceSimulationConfig`。
4. Jackpot 獎勵隨目前生成池的最高寶箱收益成長，且不會因新增低階寶箱而下降。
5. 開場與續戰填場都能依排列限制自然停止，拒絕與延後生成比例未超過具名目標上限；低密度補場後以接近 12 個有效目標為主要結果，真正清場後的無目標時間、補場頻率、未達目標短缺與收益增幅落在專屬具名目標內，且 Jackpot 追逐期間補場次數為 `0`。
6. 任一必要案例都不能出現同一段無新手動介入的持續連鎖重複補場、Jackpot 無法進入／結束、重複結算或本局無法收尾。
7. 各受影響解鎖階段的 `裝備出售收益 ÷ 本局總收益` 落在 `15%～25%` 的暫定目標內；此比例只作為驗證門檻，不得反向動態決定單件售價。
8. 無換裝、Sword 優先與 Ring 優先模型都必須保持實例守恆且落在既有擊殺、總收益與 Jackpot 成功率目標內；換裝不得改變同一批已取得裝備的出售總額。
9. 目前永久升級效果必須隨等級單調改善，固定主武器基礎傷害與手動攻擊間隔不因任何目前升級改變；自動攻擊與手動傷害占比、各級所需局數及第三槽增幅落在具名目標 config 內。
10. 受影響的人工體感項目已實際確認，沒有用模擬結果代替操作與視覺判斷。

若具名目標區間尚未建立，該平衡項目只能標記為「待校準」，不得宣告完成。第一版允許先建立暫定目標，之後依實際遊玩調整 config；調整後必須重新執行受影響案例。

#### 模擬報告

每次平衡驗證結果至少記錄：

- 使用的 config 版本或數值摘要。
- 固定 seed 集合與每個案例的樣本數。
- 實際執行的案例矩陣。
- 必要指標、目標區間與通過／失敗結果。
- 未通過項目及後續調整方向。

報告只需保存足以重現與判斷的摘要，不保存每一局的完整逐幀資料。

開發期間只維護一份[當前核心平衡報告](./balance_report.md)；每次完成新規則或數值驗證後直接取代舊內容，不保留已過時的報告或歷史通過結論。

### 18.3 人工體感優先項目

最優先驗證：

#### A. 普通箱是否能在完整 30 秒單局內持續打得舒服

需要測：

- 第一個可操作畫面是否已有自然散落且可點擊的寶箱，同時保留舒服的向下移動速度與後續進場節奏。
- 受擊停頓。
- 每個目標的武器傷害間隔是否能抑制連點造成的重複受傷與 hit 特效，同時不影響切換目標或效果卡傷害。
- 輕微裂痕是否在 70% 血量門檻後清楚出現，明顯裂縫是否在 35% 門檻後沿原裂痕自然延伸。
- 明顯裂縫的局部錯位是否足以辨識受損加重，同時不會讓卡牌在死亡前看起來已經碎裂。
- 三組裂紋變體是否能降低重複感，且同一張卡受擊時裂紋位置不會跳動。
- `normal` 是否能自然呈現「完整 → 輕微裂痕 → 擊殺破碎」；不要求它在現有兩擊死亡的平衡下停留於明顯裂縫。
- 破碎頻率。
- 金錢噴出。
- 金幣反彈、停留與集中收集是否俐落，連續擊破時是否遮擋下一個可點擊目標。
- 本局收益數字滾輪是否能跟上連續收益且最後停在正確金額。

#### B. Jackpot 現形後是否真的形成高潮

需要測：

- 移動速度。
- 變向頻率。
- Jackpot 是否確實到第 `6` 秒才從上緣首次進場，且追逐與逃跑時間仍能形成高潮。
- 點擊判定大小。
- 被打後減速／停頓。
- 偽裝外殼的裂紋是否正常累積，切換 Jackpot 真身後是否重置為完整外觀，再依真身血量重新累積。
- Jackpot 移動、反彈與微幅旋轉時，裂紋是否穩定貼合卡牌，沒有抖離或方向錯置。
- 擊殺所需時間。
- 擊殺噴幣是否明顯強於普通寶箱，但沒有因數量過多造成卡頓或拖長收尾。

#### C. 偽裝破綻是否「看得到但不必看」

需要測：

- 新手能否靠無腦掃場找到 Jackpot。
- 熟練玩家是否能用破綻提高成功率。
- 破綻是否過度明顯。

#### D. 換皮重返是否會讓玩家覺得合理

需要測：

- 玩家是否理解是同一隻 Jackpot。
- 是否會產生「反正下一個還會來」的消極策略。
- 重返間隔需要增加多少。

#### E. 裝備掉落與能力是否清楚

需要測：

- 看得見的裝備未成功掉落時，散失表現是否清楚且不讓玩家誤認已取得。
- 裝備是否比同事件金幣稍晚抵達；同批多件是否能同時飛向不同槽，滿槽時是否明確飛向背包。
- 飛行中與背包內是否保持無效，抵達裝備槽的瞬間是否容易理解為能力啟用。
- 背包面板是否只列出已完成收集的背包卡；取得時間與稀有度排序是否容易理解，重複裝備是否保持逐張可操作。
- 背包與裝備欄 hover／focus tooltip 是否能用同一段效果文字清楚解釋能力；拖曳與先選卡再選目的地是否都能可靠完成裝備、替換、卸下及槽位互換。
- 開啟背包時，主倒數、Jackpot、攻擊、掉落收集與場景動畫是否同時凍結，關閉後是否從原進度恢復且沒有瞬間補算；背景是否只有不帶濾鏡的半透明遮罩，裝備欄、槽內卡圖、拖曳預覽與 tooltip 是否保持清晰並位於遮罩上方；從卡框、卡圖或名稱開始拖曳是否都不受原生 image drag 干擾，`pointercancel` 是否只取消而不提交，保留槽是否清楚鎖定。
- Ring 的 `SR` 紫色清晰外框與模糊層基準卡形是否完全貼合 card frame，並與其他 `SR` 卡一致；只有柔光自然延伸且不形成較大的第二層外框或遮住鄰卡。追加 hit 是否以 config 固定節奏向右上錯開並呈現連擊感；即使觸發命中或前段追加攻擊已擊殺目標，剩餘動畫是否仍完整播放且不重複造成傷害或獎勵，本局結束後是否確實停止。

#### F. 效果卡是否清楚且值得追擊

需要測：

- 單張 `33 × 41` 效果卡是否固定插在右上角；用測試資料顯示 2～4 張時，是否形成整體微幅順時針的撲克扇形。
- 扇形中每張 icon 是否仍可辨識，所有突出卡片是否能精準點擊且不會在卡片間明顯空白處命中寶箱。
- 卡框、icon 與固定扇形角度是否維持清楚像素邊緣。
- `N` 卡是否完全無光暈；`R` 藍色、`SR` 紫色、`SSR` 橘金色與 `UR` 固定斜向五色光暈是否只依稀有度選取、清楚但不蓋住鄰卡 icon，並只做微弱呼吸且與卡片完全同步。所有發光稀有度的描邊必須貼齊卡框，模糊光層沿框自然衰減。
- `160 ms` 卡片噴出前搖是否俐落，玩家能理解是效果卡正在發動。
- `450 ms` 落雷動畫是否清楚有力，且不會因過慢遮擋後續操作。
- 落雷底端是否準確落在目標中心，且只有底端周圍 `88 × 88` 正方形產生範圍傷害。
- 落雷依目前 config 執行的候選抽選、初始道數與傷害倍率是否會過度提高普通收益或 Jackpot 捕獲率。
- 連鎖觸發是否令人滿足；`normal` 大量破碎的同時，`rare1`／`rare2` 是否形成短補刀而非磨血，深度連鎖是否仍能真正清場並在短促回饋後續戰，且不會無介入重複補場、重複結算或長時間阻塞操作。
- `SSR` 隕石的橘金色卡框形光暈是否清楚高於無光暈的 `N` 落雷，且不會蓋住鄰卡 icon 或搶過 Jackpot；`UR` 測試卡的五色順序是否正確、固定斜向且沒有流動。
- 普通寶箱與 Jackpot 偽裝外殼依目前 config 執行的效果卡／裝備候選抽選、共用容量裁切後，是否造成外掛卡過多或目標辨識負擔。
- Jackpot 真身從效果卡與裝備共同內容池選取後是否肉眼可見地比普通寶箱更肥，依 config 機率出現不同目標張數的比例是否符合預期。
- 縮放後的隕石順時針旋轉 `45°` 後，是否清楚從右上往左下進場，且使用縮放後 bounds 的起始位置不會先閃在畫面內。
- 調整隕石／爆炸共用顯示比例或傷害範圍寬度倍率前後，隕石飛行前端、爆炸底部與傷害區底線是否仍落在同一位置；倍率 `1` 時視覺寬度應與命中正方形一致，`1.1` 等微調值則確認額外範圍符合比例且不造成難以理解的遠距命中。
- 目前 config 的位移速度、飛行循環、多顆發射間隔與爆炸時間是否有力但不拖長或遮擋後續點擊。
- 隕石第一顆是否通常對準有效目標，選點後固定軌跡仍清楚可讀；沒有目標時等待上限後是否確實改用隨機合法落點，而非讓卡片無故失效。
- 第二顆及後續隕石是否與同一卡所有先前落點保持清楚距離；場地不足而採最遠 fallback 時是否仍避免明顯疊在同一位置。
- 龍捲風三段動畫是否在移動中自然銜接，`run` 遊走、碰牆反射、多顆分向、底端向上傷害範圍與每目標間隔是否符合 config，並確認主倒數結束後立即消失且停止傷害。

#### G. 手動點擊特效是否提升打擊感

需要測：

- 使用 `manualHitEffect.displayScale` 縮放後的 `350 × 218` frame 與 `manualHitEffect.animationDurationMs` 設定時間，在 normal、rare 與移動中的 Jackpot 上是否大小適中、收尾俐落。
- 特效是否準確出現在游標點擊位置；點擊突出效果卡時也不會錯位到寶箱中心。
- 致死點擊移除寶箱後特效是否仍能播完；同一目標間隔內的連續點擊不得追加傷害或 hit 特效，打破偽裝後剩餘間隔必須延續到 Jackpot 真身。

#### H. 結算是否足夠短

理想狀態：

- 能立即區分戰鬥收益、裝備出售收益與最終總收益。
- 重複裝備只顯示合併數量與小計，不顯示單價。
- 逐列揭示與總收益滾動在 config 上限內完成，點擊可立即快轉；零裝備不產生空白等待。
- 顯示快轉、卸載或中斷不會再次入帳或改變存檔結果。
- 幾秒內買完升級。
- 馬上再開下一局。

#### I. 永久升級是否形成清楚的下一局期待

需要測：

- 兩條短成長線是否能在同一層看懂目前效果、下一級效果與價格，不需要理解大型技能樹，也沒有殘留不可購買的主武器升級卡。
- 固定主武器基準搭配局內 Sword、Ring 與效果卡時，是否仍能形成可感知的單局成長；第一局後可能沒有永久升級可買時，`rare1` 解鎖與下一個存錢目標是否足以維持方向感。
- 解鎖自動攻擊後是否明顯降低疲勞，間隔 1～3 級是否逐級可感知，但手動點擊仍能明顯加速。
- 自動攻擊是否確實不增加 Ring 計數，也沒有觸發手動限定效果。
- 裝備槽 III 是否增加本局形成組合的機會，但沒有讓裝備取得、前兩槽選擇或 Jackpot 高潮失去價值。
- 結算後是否常出現「再一局就買得到下一級」的接近感，同時不要求每局固定買到升級。

## 20. 核心設計原則

1. 普通階段必須能無腦玩。
2. Jackpot 揭露前的行為細節只能提供優勢，不能成為必修。
3. Jackpot 必須是每局最大的期待與操作高潮。
4. 裝備、效果卡與高級寶箱只能作為中小型誘惑，不與 Jackpot 搶主角地位。
5. 寶箱離場代表錯過機會，不代表直接受傷。
6. Jackpot 逃跑代表失去最大獎，不額外雙重懲罰。
7. 局內裝備提供即時變強感，局外貨幣提供穩定長期進度。
8. 每一局應短、結算應快、下一局應立即開始。
9. 任何新系統都必須先回答：它是否會讓玩家停止無腦敲箱？
10. 宣傳與視覺必須突出「普通卡很規律，只有 Jackpot 突然活起來」這個反差。
