# 初版單關卡與前三局解鎖規格

本文件定義初版唯一關卡、三種寶箱怪的解鎖順序，以及它們與普通生成池、Jackpot 偽裝池、效果卡、裝備、主武器、永久升級與結算流程的關係。共通遊戲規則以 [spec.md](./spec.md) 為入口；主武器購買與數值階梯見[主武器商店規格](./weapon_shop.md)，永久成長見[永久升級規格](./permanent_upgrades.md)，效果卡細節見[效果卡規格](./effect_cards.md)，三種寶箱在效果連鎖中的耐久分工與低密度補場見[連鎖清場與低密度續戰補場規格](./chain_clear_and_refill.md)，裝備細節見[裝備卡與局內裝備系統規格](./equipment_system.md)。

## 1. 初版範圍

- 初版只有一個關卡，玩家不需要選關。
- 初版先以桌面瀏覽器與滑鼠操作為目標，不在本階段處理觸控版面與行動裝置操作最佳化。
- 應用必須先完成存檔載入與 PixiJS 資源初始化，再由玩家按下開始按鈕建立開場預填並啟動主倒數；載入完成不得自動開局。
- 玩家取得操作權時，場上已依生成權重與排列限制自然預填所有已解鎖種類中的普通寶箱，不從空場等待第一隻進場。
- 初版主倒數固定以 `roundConfig.durationMs` 管理，初始值為 `30_000`；React 只顯示倒數，不保存另一份時間。
- 初版寶箱怪為 `normal`、`rare1`、`rare2`。
- 第一局就有 Jackpot，Jackpot 不需要額外解鎖。
- 本次第一階段實作以可重複遊玩的最小端到端版本為界，包含：
  - `normal` → `rare1` → `rare2` 的解鎖與生成池變化。
  - 點擊、傷害、擊破、收益與單局統計。
  - 無軌道散落排列與正式／裝飾生成模式。
  - 擊破後有效目標 `≤ 6` 的低密度判定、沿用普通生成池補向 12 個有效目標的場內續戰補場，以及同一段沒有新手動介入的持續連鎖最多補場一次；只有真正清空才顯示 `CLEAR!`，Jackpot 追逐期間不補場。
  - Jackpot 偽裝、重返、揭露、反彈追逐、擊破與逃跑。
  - 初版落雷、`SSR` 隕石與 `SR` 龍捲風效果卡的附著、顯示、擊破觸發、範圍傷害與連鎖；隕石第一顆偏向有效目標、沒有目標時等待後改用隨機合法落點，後續各顆與同一卡先前落點保持距離，龍捲風則依序播放開始、持續與結束階段並只在持續階段造成接觸傷害，實際比例與時間都依 config。
  - `sword`、`ring` 的可見／隱藏掉落、基礎 2 格局內通用裝備槽、自動裝備、可暫停背包管理、局內換裝與戰鬥效果；各項數值以裝備 config 為準。
  - 回合結束時自動出售本局成功取得的全部裝備，依裝備 id 合併顯示小計，最後併入本局總收益。
  - 新存檔持有旅行者木槌，局外武器商店依序提供破鎖鐵鎚與符文破城鎚，並保留解鎖懸停自動攻擊、自動攻擊間隔 1～3 級，以及使下一局增加為 3 格的「裝備槽 III」永久里程碑；不保留主武器微幅攻擊力升級。
  - 手動、懸停自動與 Ring 共用 `effects/hit.png` 武器命中特效：手動置中於實際點擊位置，自動依攻擊當下最新游標位置向左下偏移，Ring 依觸發批次的手動點擊位置快照向右上偏移；後兩者使用各自 config tint。
  - 主倒數條、Jackpot 倒數條、結算與解鎖提示。
  - IndexedDB 存檔、進度匯出／匯入與完整重置。
  - 核心邏輯測試與固定 seed 的批次平衡模擬。
- 本次第一階段納入 `N` 落雷、`SSR` 隕石、`SR` 龍捲風、`N／R／SR／SSR／UR` 共用稀有度光暈規則、三種武器命中特效位置／色彩、Sword／Ring 的完整局內裝備切片、背包管理與換裝、結算自動出售、三把純傷害主武器商店，以及目前兩條永久升級；不包含炸彈、冰凍、時鐘、特殊素材、音效、武器圖片、武器特殊攻擊、手動選擇出售、裝備跨局保存、主武器微幅攻擊力、手動攻速、裝備回收／掉落率或其他局外升級。效果卡與裝備不得以重複完整內容識別填滿同一攜帶者容量。

## 2. 寶箱怪強度階梯

三種寶箱怪不是單純換皮，而是不同數值的敵人：

| 寶箱怪 | 初始狀態 | 血量 | 連鎖定位 | 基礎收益 | 外掛卡容量 |
| --- | --- | --- | --- | --- | ---: |
| `normal` | 初始解鎖 | 最低 | 可被初始落雷或單顆隕石擊破的連鎖燃料 | 最低 | 1 |
| `rare1` | 完成生涯第一局後解鎖 | 高於初始單顆隕石傷害 | 單段效果後留下短補刀 | 高於 `normal` | 1 |
| `rare2` | 完成生涯第二局後解鎖 | 高於一張初始隕石卡全部隕石的總傷害 | 淺層連鎖後的耐久錨點 | 高於 `rare1` | 2 |

規則：

- 最大血量、基礎收益與生成權重必須使用清楚名稱放在 config。
- 寶箱怪越難打破，收益必須相應提高。
- 第一輪主武器階梯以 `rare1` 在旅行者木槌下 5 擊、破鎖鐵鎚下 2 擊，以及 `rare2` 在破鎖鐵鎚下 5 擊、符文破城鎚下 2 擊為明確門檻；實際血量、收益與武器傷害仍只存正式 config。
- 「需要攻擊幾下才擊破」應由寶箱最大血量與玩家實際攻擊力推導，不另外保存一份重複數字。
- 解鎖高階寶箱怪不會移除先前種類；所有已解鎖種類都保留在生成池中。
- `normal` 維持生成池多數；`rare1`／`rare2` 的生成權重必須讓殘存目標穩定可見但不把普通掃場拖成逐隻磨血。
- 不新增效果抗性、連鎖傷害遞減或護盾來達成上述分工；深度連鎖與玩家事前削血仍必須能真正清場。
- 實際平衡數字不在規格文件寫死，應透過 config 與體感模擬調整。

## 3. 單一關卡生成池

- 初版關卡的普通生成池，等於所有已解鎖寶箱怪的集合。
- 每種寶箱怪依自己的生成權重抽選，因此「已解鎖」不代表出現機率相同。
- 生成位置採無軌道的受限隨機分布，詳細演算法邊界見[前端與遊戲執行架構](./technical_architecture.md)。
- 開場填場、低密度續戰補場與後續上緣生成共用普通生成池、候選位置、最大重疊比例及內容附著流程；兩種場內填場的寶箱都會正常建立效果卡、可見／隱藏裝備、血量與收益資料。
- 開場填場由同一排列演算法持續放置，直到沒有合格候選位置或達到既有全場同時存在上限；續戰補場另在有效目標達到 config 目標 `12` 時停止。場內填場區排除 config 指定的畫面底部不可生成範圍，避免寶箱建立後立即離場。
- 續戰補場保留上方既有寶箱並讓它們繼續向下移動，不重設普通上緣生成、Jackpot 首次生成或重返計時；補場不建立 Jackpot。
- 普通生成池是關卡內容的唯一來源；不得另外維護一份容易不同步的 Jackpot 可用種類清單。

## 4. Jackpot 規則

- Jackpot 不加入開場預填；每局首次偽裝在主倒數開始後第 `6` 秒才依當下偽裝池從場地上方嘗試生成，未揭露離場後的重返間隔不受這個首次延遲取代。

### 4.1 第一局

- 第一局已包含 Jackpot。
- 第一局普通生成池只有 `normal`，因此第一局的 Jackpot 只能偽裝成 `normal`。

### 4.2 偽裝池

- Jackpot 偽裝池必須由目前關卡實際可生成的寶箱怪種類推導。
- `rare1` 解鎖後，普通生成池與 Jackpot 偽裝池都加入 `rare1`。
- `rare2` 解鎖後，普通生成池與 Jackpot 偽裝池都加入 `rare2`。
- Jackpot 換皮重返時，也只能從同一個偽裝池抽選。
- Jackpot 偽裝外殼的外掛卡容量與附著規則沿用當次外皮；不得用較多插卡提前暴露身份。
- 打破偽裝外殼時維持不掉金錢，但外殼上的效果卡必須正常觸發，可見裝備依 config 判定掉落，內部隱藏裝備也完成結算。
- 偽裝外殼的外掛卡在破殼時完成結算，不轉移到真身；揭露後的 Jackpot 依真身 config 與內容池建立新的外掛卡集合。
- Jackpot 真身不套用普通候選機率，目標張數與選取權重依真身 config，並從效果卡與裝備的共同內容池公平、無重複選取。可用唯一內容不足時全部插上，不以重複卡補滿。真身另行產生自己的內部隱藏裝備；擊破時獨立結算，並可與 Jackpot 金幣噴獎並行。

### 4.3 獎勵基準

- 每局先找出目前關卡可生成寶箱怪中最高的基礎收益。
- Jackpot 獎勵以該最高收益為基準，再依 Jackpot config 定義的規則放大。
- 放大倍率、額外獎勵及可能的隨機浮動都屬於可調數值，不在遊戲邏輯中寫死。
- 因為可生成的最高階寶箱怪會隨解鎖改變，Jackpot 獎勵也會隨進度成長。

## 5. 生涯局數與解鎖

### 5.1 計數規則

- 每次主倒數結束並完成本局收尾，生涯完成局數增加一次。
- Jackpot 被擊殺或逃脫都不影響局數計算。
- 局數、解鎖結果與待展示提示必須寫入 IndexedDB 存檔。

### 5.2 固定解鎖順序

| 完成本局前的可用種類 | 完成本局後 | 新解鎖 |
| --- | --- | --- |
| `normal` | 生涯完成局數變為 1 | `rare1` |
| `normal`、`rare1` | 生涯完成局數變為 2 | `rare2` |
| `normal`、`rare1`、`rare2` | 生涯完成局數大於 2 | 無固定寶箱怪解鎖 |

### 5.3 解鎖展示順序

流程固定為：

1. 本局結束。
2. 禁止新的戰鬥結果，凍結本局戰鬥收益與成功取得裝備的出售快照；倒數結束前已成功掉落但仍在飛行中的裝備也包含在快照內。
3. 取消飛行動畫、槽位保留與 Ring 待結算追加攻擊，再清除局內裝備與背包內容；失敗掉落及仍附著於未擊破目標的裝備不出售。
4. 依稀有度價格規則計算裝備出售收益，與戰鬥收益合併為本局總收益，同時計算完成局數、新解鎖與待展示提示。
5. 將本局總收益與進度變更作為同一份一致結果寫入存檔；寫入成功後才顯示結算內容。
6. 先快速顯示戰鬥收益，再依裝備 id 合併顯示出售小計，最後顯示本局總收益、擊破數與 Jackpot 結果。
7. 結算揭示完成後，才顯示新寶箱怪解鎖提示。
8. 玩家回到可以主動購買局外升級或再次開始的介面。

局外升級不是結算流程中的強制步驟，不得延後解鎖提示等待玩家購買升級。

### 5.4 中斷恢復

- 解鎖提示顯示前，必須先持久化「待展示」狀態。
- 玩家若在解鎖提示完成前關閉遊戲，下次載入存檔後必須補播。
- 玩家確認提示後，才將該提示標記為已展示並再次存檔。
- 已確認的解鎖提示不得在後續正常啟動時重複播放。

## 6. 結算背景模式

本局進入結算後，戰鬥場地仍作為 React UI 下方的動態背景：

- PixiJS 畫面與基礎移動動畫持續更新。
- 沿用正式生成器，但切換為裝飾模式，不建立平行生成系統。
- 裝飾模式繼續依權重生成所有已解鎖寶箱怪。
- 裝飾寶箱不得附帶裝備卡或效果卡。
- 裝飾模式不得生成 Jackpot。
- 裝飾寶箱不可受擊，不計算血量、收益、掉落或本局統計。
- React 覆蓋層攔截操作，遊戲流程也必須拒絕任何戰鬥事件。
- 下一局開始前，清除所有裝飾實體，再建立新的正式單局內容。

## 7. 初版行為驗證

至少驗證以下行為：

- 新存檔第一局只生成 `normal`，但確實包含偽裝成 `normal` 的 Jackpot。
- 第一局不論 Jackpot 成敗，結算後都解鎖並展示 `rare1`。
- 第二局可生成 `normal` 與 `rare1`，Jackpot 也只能在這兩種偽裝中選擇。
- 第二局不論 Jackpot 成敗，結算後都解鎖並展示 `rare2`。
- 第三局開始可生成三種寶箱怪，Jackpot 偽裝池與普通生成池一致。
- `normal`、`rare1`、`rare2` 分別符合連鎖燃料、短補刀與耐久錨點的傷害門檻；普通連鎖保留少量高階目標，深度連鎖或事前削血仍可完整清場。
- 擊破使有效目標降至 `6` 隻或以下時依[連鎖清場與低密度續戰補場規格](./chain_clear_and_refill.md)確認並補向 `12` 隻；自然流出不主動觸發、Jackpot 追逐期間不補，上方既有寶箱不中斷，同一段沒有新手動介入的持續連鎖不會重複補場，只有確認時為零才顯示 `CLEAR!`。
- 正式單局中的普通寶箱與 Jackpot 偽裝外殼依各卡 config 建立效果卡與裝備候選，超過共用容量時公平隨機裁切；固定 seed 下結果可重複。
- 揭露後的 Jackpot 真身從目前效果卡與裝備共同內容池無重複選取；目標張數依 Jackpot config 機率決定並受最少／最多張數限制。
- 單張外掛卡使用固定位置，多張時依數量與索引形成確定性扇形；任何內容都不得因箱種或 Jackpot 容量較大而重複生成。
- `N` 卡不顯示光暈；`R` 藍色、`SR` 紫色、`SSR` 橘金色與 `UR` 固定斜向五色卡框形光暈只做微弱透明度呼吸，必須與卡片同步移動且不得覆蓋其他卡片 icon。效果卡與裝備只依稀有度共用資源，不建立依內容名稱分流的光暈。
- 落雷、隕石與龍捲風傷害、連鎖及 Jackpot 互動符合[效果卡規格](./effect_cards.md)，且不會重複結算死亡或收益。
- 主倒數在效果卡噴出前搖期間耗盡時，尚未發動的攻擊會被取消；尚未發射或仍在飛行的隕石與所有階段的龍捲風也不得在倒數後造成傷害。
- 有效手動點擊會在實際點擊位置置中播放 5 幀武器 hit；有效懸停自動攻擊使用當下最新游標位置的左下 config 偏移／tint；Ring 使用觸發批次之手動點擊位置快照的右上 config 偏移／tint。三者共用 `animationConfig.weaponHitEffect` 的圖帶、顯示比例、播放器與時間；效果卡傷害不播放武器 hit。
- 同一目標接受武器傷害的最短間隔依 `combatConfig.minimumWeaponDamageIntervalPerTargetMs`；間隔內的點擊不造成傷害或受擊回饋，不同目標各自計算。效果卡不受此限制，Jackpot 偽裝外殼剩餘間隔則延續到真身。
- 可見裝備掉落、內部隱藏裝備、同批槽位保留、滿槽進背包與抵達後生效符合[裝備卡與局內裝備系統規格](./equipment_system.md)；Sword 與 Ring 的結果皆讀取正式 config。
- 開啟背包時預設完整凍結主倒數、Jackpot、攻擊與遊戲動畫；背景只使用不帶濾鏡的半透明遮罩，裝備欄、槽內卡圖、拖曳預覽與 tooltip 位於其上且保持清晰，不沿用結算高斯模糊。背包清單、兩種排序、tooltip、保留槽鎖定、拖曳與點選替代換裝都符合裝備規格，原生圖片 drag 不搶走 pointer，取消拖曳不提交，恢復時不補算暫停時間。
- 新存檔只持有並裝備旅行者木槌；三把武器從一開始都顯示，後兩把依前置與正式 weapon config 購買，已持有武器可在局外免費切換裝備。開局快照決定本局主武器，自動攻擊與 Sword／Ring 沿用該快照，效果卡則固定使用初始武器基準；不存在主武器微幅攻擊力等級。
- 自動攻擊解鎖／間隔等級 `0～3` 及裝備槽等級 `0～1` 直接讀取正式永久升級 config，手動攻擊間隔不隨任何目前升級或主武器階段改變。
