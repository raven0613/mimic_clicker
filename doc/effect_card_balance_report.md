# 效果卡與裝備系統暫定平衡報告

本報告承接[局外成長、內容與驗證規格](./progression_and_validation.md)的初版核心平衡驗證閘門，記錄 `tornado-effect-card-v11` 的可重複模擬結果。此版本在既有落雷、隕石、Sword 與 Ring 基礎上，加入 `SR` 龍捲風的候選抽選、Jackpot 保證選卡、三階段生命週期、移動接觸傷害、每目標間隔、死亡連鎖與主倒數取消。

## 模擬版本與案例矩陣

- config 版本：`tornado-effect-card-v11`。
- 固定 seed：`11`、`29`、`47`、`83`、`131`、`197`、`263`、`347`、`431`、`557`、`683`、`809`。
- 3 種解鎖生成池 × 3 種點擊速度 × 3 種命中率 × 4 種 Jackpot 路徑 × 6 種裝備 loadout × 12 個 seed。
- 合計 `7,776` 個可重複案例；同一完整矩陣連跑兩次結果相同，所有案例均正常收尾。

模擬直接讀取正式 config。三種效果卡與兩種裝備先進入同一候選池，再依寶箱容量公平裁切，因此下表的「實際附著率」不是候選抽選率的另一份設定值，也不要求等於候選率；候選率本身由 config 與核心規則測試驗證。Jackpot 真身依 config 的張數範圍從完整唯一內容池選卡。

落雷依有效目標與底端範圍結算一次傷害；隕石依 config 的顆數、發射間隔、飛行速度、顯示比例與傷害範圍倍率計算落點和落地時間。龍捲風從攜帶者位置完成 `start` 位移後進入 `run`，用共用移動、轉向、反射、碰撞與傷害範圍規則推進；接觸傷害依 config 的單目標間隔取樣，`run` 結束或主倒數耗盡後不再結算。效果擊破會將攜帶卡重新排入 `160 ms` 前搖，形成可重複且有限的連鎖事件序列。

## 判定與限制

`tornado-effect-card-v11` 通過目前的自動化平衡閘門；報告由 `npm run test:balance` 產生。三種效果卡都能生成與觸發，龍捲風能造成接觸傷害、擊破與連鎖，收益階段成長、裝備掉落／啟用及所有回合收尾仍在暫定目標內。

固定操作模型用來比較數值趨勢，不包含人類游標移動、卡片辨識延遲、動畫注意力成本或畫面遮擋。龍捲風三段銜接、移動讀感、碰牆反射、卡框形光暈、實際接觸範圍、多顆分向與 Jackpot 變身後立即重置傷害間隔，仍須在遊戲中依人工檢查清單確認。若人工測試後調整任何會影響結果的 config，必須重跑相同完整矩陣並更新本報告。
