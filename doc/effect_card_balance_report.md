# 效果卡與裝備系統暫定平衡報告

本報告承接[局外成長、內容與驗證規格](./progression_and_validation.md)的初版核心平衡驗證閘門，記錄 `initial-field-prefill-v12` 的可重複模擬結果。此版本涵蓋落雷、隕石、龍捲風、Sword、Ring、共同外掛內容池、開場自然預填，以及 Jackpot 首次延後至主倒數第 `6` 秒從上緣生成。

## 模擬版本與案例矩陣

- config 版本：`initial-field-prefill-v12`。
- 固定 seed：`11`、`29`、`47`、`83`、`131`、`197`、`263`、`347`、`431`、`557`、`683`、`809`。
- 3 種解鎖生成池 × 3 種點擊速度 × 3 種命中率 × 4 種 Jackpot 路徑 × 6 種裝備 loadout × 12 個 seed。
- 合計 `7,776` 個可重複案例；同一完整矩陣連跑兩次結果相同，所有案例均正常收尾。

模擬直接讀取正式 config。開場使用正式矩形候選選擇器，在排除底部不可生成區後自然填入寶箱，直到無合法位置或達到全場上限；預填寶箱與後續上緣生成都計入相同的權重、附著內容、移動、戰鬥與收益模型。三種效果卡與兩種裝備先進入同一候選池，再依寶箱容量公平裁切，因此下表的「實際附著率」不是候選抽選率的另一份設定值。Jackpot 不加入預填，首次機會從第 `6` 秒開始，真身仍依 config 的張數範圍從完整唯一內容池選卡。

落雷依有效目標與底端範圍結算一次傷害；隕石依 config 的顆數、發射間隔、飛行速度、顯示比例與傷害範圍倍率計算落點和落地時間。龍捲風從攜帶者位置完成 `start` 位移後進入 `run`，用共用移動、轉向、反射、碰撞與傷害範圍規則推進；接觸傷害依 config 的單目標間隔取樣，`run` 結束或主倒數耗盡後不再結算。效果擊破會將攜帶卡重新排入 `160 ms` 前搖，形成可重複且有限的連鎖事件序列。

## 判定與限制

`initial-field-prefill-v12` 通過目前的自動化平衡閘門；報告由 `npm run test:balance` 產生。開場預填能自然停止、後續生成保持運作、三種效果卡都能生成與觸發，收益階段成長、裝備掉落／啟用、Jackpot 捕獲及所有回合收尾仍在暫定目標內。

固定操作模型用來比較數值趨勢，不包含人類游標移動、卡片辨識延遲、動畫注意力成本或畫面遮擋。開場散落感、底部留白、第一個可操作畫面、Jackpot 第 `6` 秒進場體感，以及龍捲風三段銜接與碰牆讀感，仍須在遊戲中依人工檢查清單確認。若人工測試後調整任何會影響結果的 config，必須重跑相同完整矩陣並更新本報告。
