# 落雷與隕石效果卡暫定平衡報告

本報告承接[局外成長、內容與驗證規格](./progression_and_validation.md)的核心平衡驗證閘門，記錄 `per-target-weapon-damage-interval-v8` 的可重複模擬結果。此版本同時納入落雷、隕石／爆炸顯示與傷害範圍比例、Jackpot 真身保證選卡與 config 張數機率，以及每目標武器傷害間隔。

## 模擬版本與案例矩陣

- config 版本：`per-target-weapon-damage-interval-v8`。
- 固定 seed：`11`、`29`、`47`、`83`、`131`、`197`、`263`、`347`、`431`、`557`、`683`、`809`。
- 3 種解鎖生成池 × 3 種點擊速度 × 3 種命中率 × 4 種 Jackpot 路徑 × 12 個 seed。
- 合計 `1,296` 個可重複案例，全部可正常收尾。

模擬直接讀取正式 config，並納入兩種卡對普通寶箱／Jackpot 偽裝外殼的候選抽選、容量公平裁切、效果卡去重、`160 ms` 前搖、死亡連鎖與倒數取消。Jackpot 真身依最少／最多張數與各自 config 機率保證選取；目前內容池只有落雷與隕石，因此揭露後必定同時插上兩張。報告的候選附著率只統計普通寶箱與偽裝外殼，不讓真身保底扭曲普通機率；每局平均附帶與觸發則包含真身卡片。

武器攻擊嘗試依 `combatConfig.minimumWeaponDamageIntervalPerTargetMs` 對每個目標分別判定；被拒絕的嘗試不計傷害，Jackpot 偽裝外殼揭露後延續同一目標的剩餘間隔。落雷與隕石傷害不套用或更新此間隔。

落雷使用隨機有效目標、底端 `88 × 88` 範圍與單道一次傷害。隕石使用本次 config 的每卡 `3` 顆、`800 px/s`、`200～300 ms` 發射間隔、隨機合法落點與場外起點推導；`displayScale` 為 `0.75`、`damageAreaWidthMultiplier` 為 `1.1`，所以爆炸顯示寬度為 `192 px`，底部對齊的傷害正方形邊長為 `211.2 px`。飛到主倒數後才落地的隕石不計傷害或連鎖。

## 判定與限制

`per-target-weapon-damage-interval-v8` 通過目前的自動化平衡閘門；報告由 `npm run test:balance` 產生。每目標武器傷害間隔、兩種卡的普通候選附著率、Jackpot 真身保底、收益階段成長、效果傷害、有限連鎖與回合收尾都在暫定目標內。

模擬以固定操作模型比較數值趨勢；Jackpot 路徑由案例矩陣指定，偽裝外殼的隕石命中以可重複的場中央追逐位置近似，不重播完整逐幀反彈軌跡。模擬也不包含人類游標移動、卡片辨識延遲或動畫注意力成本。因此橘黃色光暈、點擊位置特效、隕石進場方向、爆炸底線對齊、遮擋與打擊感仍需在實際遊戲中人工確認；若人工測試後調整任何結果相關 config，必須重跑相同案例矩陣。
