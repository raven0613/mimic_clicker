# 落雷效果卡暫定平衡報告

本報告承接[局外成長、內容與驗證規格](./progression_and_validation.md)的核心平衡驗證閘門，記錄 `initial-thunder-jackpot-card-v4` 的可重複模擬結果。此版本使用落雷底端周圍的 `88 × 88` 正方形命中範圍，並納入箱種外掛卡容量、效果卡去重與 Jackpot 真身獨立插卡。

## 模擬版本與案例矩陣

- config 版本：`initial-thunder-jackpot-card-v4`。
- 固定 seed：`11`、`29`、`47`、`83`、`131`、`197`、`263`、`347`、`431`、`557`、`683`、`809`。
- 3 種解鎖生成池 × 3 種點擊速度 × 3 種命中率 × 4 種 Jackpot 路徑 × 12 個 seed。
- 合計 `1,296` 個可重複案例，全部可正常收尾。

模擬直接讀取正式 config，並納入 `6%` 附著抽選、箱種容量、效果卡去重、`160 ms` 前搖、初始落雷道數、三倍初始武器傷害、隨機有效目標、以動畫單格寬度推導的底端 `88 × 88` 範圍命中、每道一次傷害與連鎖佇列。Jackpot 偽裝外殼沿用外皮容量並在破殼時結算；揭露後的真身獨立抽選，真身擊破時的落雷也排入普通寶箱戰鬥時間線。普通寶箱則以生成時間、位置與移動速度執行逐次攻擊及範圍判定。

## 判定與限制

此處代表 `initial-thunder-jackpot-card-v4` 通過目前的自動化平衡閘門；報告由 `npm run test:balance` 產生。箱種容量、效果卡去重與 Jackpot 真身獨立插卡加入後，目標操作模型、收益成長、效果卡附著率與連鎖收尾仍在暫定目標內。

模擬用於比較數值趨勢，不模擬人類游標移動、目標辨識延遲或動畫注意力成本。卡片辨識度、突出區域點擊精度、`160 ms` 前搖、`450 ms` 動畫速度、畫面遮擋與連鎖體感仍須在實際遊戲中人工確認；若人工測試後調整任何結果相關 config，必須重跑相同案例矩陣。
